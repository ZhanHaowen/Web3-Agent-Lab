# Web3 Agent Lab V0.12 版本说明

V0.12 将此前 V.011 金额修复版的功能汇总为公开发行版本。程序版本为 **0.1.2**，显示版本与发行标识为 **V0.12**，修订标识为 **beta-1**，独立检查器保持 **2.1.0**。本次统一版本、发行文档与部署包名称；金额修复、连续实验和溯源图均沿用已实现的行为，没有宣称新增协议或模型能力。固定依赖与原始记录格式保持不变。

## 当前功能

- 本地 GUI 运行查询余额、转账、代币授权、兑换、兑换后存入五种基准任务；任务结果由独立检查器依据链上证据判定。
- 独立模式恢复标准初态；连续模式继承真实余额、授权、池储备与仓位，并保存会话及前一轮编号。
- 默认 `fixed_task` 策略在签名前检查固定任务金额。`amount`、`amountIn`、`minAmountOut` 均使用人类可读代币数量字符串；授权 20 TokenA 应填 `"20"`，链工具仅转换一次，链上整数为 `20000000`。
- 参数金额错误返回 `TOOL_AMOUNT_MISMATCH`，保留模型提议与拒绝记录，允许 Agent 重新调用；不会擅自除以 1000000 修正。研究错误金额时可显式选择 `schema_only`，类型、格式和最多 6 位小数约束仍生效。
- 检查器按成功交易 nonce 顺序重放授权覆盖与后续消耗，允许兑换或存入之前的合规重复授权。超额授权、错误对象及任务后的额外授权仍独立判失败。缺失顺序证据时不推测。
- 轨迹关联任务、模型调用、工具调用、合约调用、交易和 EVM 内部调用，保存参数、原始与可见结果、回执、原始事件引用。GUI 可展开详情、点击图节点查看属性与关系。

## 图数据与离线分析

完整实验包包含原始事件、内容寻址文件及独立派生视图。封存运行会自动生成以下文件至 `data/derived/<run_id>/`，导出时会校验原始证据并重新生成：

| 文件 | 用途 |
| --- | --- |
| `execution-trace.json`、`execution-trace.md` | 结构化及可阅读的详细轨迹 |
| `provenance-graph.json`、`provenance-graph.graphml` | 通用有向多重溯源图 |
| `nodes.csv`、`relations.csv` | 节点与关系列表 |
| `trace-events.jsonl` | 展开负载的事件便利副本 |
| `execution-trace-manifest.json` | 派生文件哈希及源清单引用 |

图结构不宣称符合特定 PGG 或 W3C PROV 规范。执行关系使用显式调用 ID、交易哈希及 EVM trace 父子关系；时间先后单独标记，不作为因果推断。旧包未采集的证据和关系不补造。原始文件清单验证完整性，不证明来源真实性，也不认证派生图结论。

离线查看时启动本地 GUI 服务，在「实验档案」中「打开导出包」，选择完整实验 JSON。此操作不调用模型或实验链，可以展开调用、点击图节点并下载 JSON 或 GraphML。单独图文件用于图分析，不替代完整实验包回放。CLI 的 `trace`、`graph`、`trace-files` 同样支持离线提取；格式见[执行轨迹与溯源图说明](trace-schema.md)。

## 安装与升级

Windows x64 和 macOS 部署包自带 Node.js、Anvil 及编译程序，日常使用无需 Docker 或开发工具。完整解压至可写目录：Windows 双击 `start.cmd`，macOS 双击 `Start.command`。本地界面默认地址为 `http://127.0.0.1:4317`，实验链 RPC 端口为 8547。

Windows 包适用于 Windows 10/11 x64；附带 macOS 二进制声明的最低版本为 Apple Silicon macOS 15.5、Intel macOS 13.5。macOS 尚未完成实机验收；CI 结果也不能替代发布包的桌面操作验证。遇到权限或来源提示时按[操作手册](操作手册.md)处理，不要求关闭系统安全功能。

1. 正常停止旧程序，备份整个 `data` 目录。
2. 将 V0.12 解压至新目录，保留旧软件包与原始数据，不覆盖升级。
3. 旧实验包可在新版离线打开。如需原档案列表，在两版程序均停止后复制完整 `data`，保留原副本。
4. 原始记录与历史标签不自动重写。新版复检追加检查器 2.1.0 的结果，分析时保留检查器版本和证据来源。
5. 历史超额授权不会自动撤销；需要干净初态时明确恢复环境或选择独立实验。旧版本原配置重跑应使用原软件包。

版本升级后源码哈希发生变化，不会把新版执行冒充旧构建的原配置重跑。连续实验仍不支持跨会话自动恢复任意历史起点；可在同一链进程内提前保存并显式恢复快照，再新建连续实验。

## 验证与边界

当前测试记录见[验证说明](validation.md)。此前金额修复版已通过真实 Windows/Anvil、接口、浏览器及部署包验收；发布版本仍应以本次构建的验证记录为准。模型链路测试使用本地协议模拟服务，不代表真实 LLM 能力或全部兼容端点验证。macOS 未完成实机验证。

平台仍为单机、单 Agent、顺序实验环境，不提供多租户、并发调度或桌面自动更新。主网分叉上仍部署本地实验 AMM 与 Vault，没有自动接入真实 Uniswap/Aave。实验账户、资产和固定密钥仅用于本地测试，不能用于生产资金。

既有修订的历史说明保存在[版本说明 V.011](版本说明_V.011.md)。
