## 5. 协议与研究边界

- AP2 仅实现本地签名 mandate 子集叠加 x402；不是完整 SD-JWT/凭证生态互操作认证。x402 当前验证 EIP-3009 路径，不含 Permit2 支付路径。
- MPP 仅为 EVM charge；Tempo session、Stripe、外部商户、MCP 扩展未运行。ERC-8183 为本地核心托管，不包含 hooks、费用、ERC-2771 或 Virtuals SDK。
- batch 使用官方合约运行时代码在 Anvil 中装载，记录来源；不是生产部署验证。通道状态仍在内存中，不能跨进程自动恢复付款。未决结果需人工核验，不能自动重复付费。
- 采购服务与语料为自建构造环境；背景交易为同 token、同商户价格档位的顺序交错，不是并发真实用户流量。
- 公开观察由 RPC 采集区块、交易、calldata、回执与日志；攻击进程只得到许可特征和标签。这是输入隔离，不是操作系统沙箱；当前仍假定已知实验窗口。
- 独立检查器验证台账与公开引用一致性，不是全部支付语义的形式化证明。RPC 没有共识认证；内部原生资产转移尚未完整解码。`windowGasUsed` 包含整个窗口的初始化/背景交易，不能当作 Agent 净 gas。
- 尚未全面验证隐私支付部署、跨模型泛化、未知任务与长期混合交易的自动分段。小样本上的指标不应直接作为论文隐私攻击结论。

## 6. 复现与证据

使用锁定的 Node 24.19.0 和依赖，先完成 [操作说明](V0.17.0-RESEARCH-GUIDE.md) 的安装。根目录执行：

```text
pnpm install --frozen-lockfile
pnpm run setup:research
pnpm run build
pnpm run typecheck
pnpm run test:unit
pnpm run test:research:chain
node tests/research-portable.mjs
```

真实模型回归另运行 `node tests/research-local-model.mjs`，需要本机安装对应模型和推理运行时；没有模型时应报告未执行，不以 fixture 替代。`tests/research-dataset-smoke.mjs` 用于构造样本流程验证。原功能可分别运行 `tests/v2-integration.mjs`、`tests/peer-integration.mjs`、`tests/peer-contract.mjs`、`tests/service-integration.mjs` 与预算测试。

重新运行会生成新的目录、时间、签名和交易哈希；只要求相同配置与明确的比较口径，不声称整个实验逐字节一致。公开摘要索引列出原证据相对路径和 SHA-256；原始私有数据保存在本地评审包，未纳入公共 Git 仓库。
