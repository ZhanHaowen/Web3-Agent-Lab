# V0.15 更新说明

V0.15 在 V0.14.2 的双 Agent 场景和反馈体验之上，新增“购买 Agent 服务”页面与service_purchase模板，首个服务为固定区块结构化余额报告。

新增Buyer与Provider独立会话、私有目标和钱包，以及无需LLM的独立Evaluator。新合约LabServiceEscrow实现创建、精确预算出资、提交产物哈希、验收付款、拒绝退款、到期退款、未出资取消。事后Checker读取固定区块并与实际支付对比，不能因为Evaluator批准或合约付款而放过错误报告。

支持正确报告、错误余额、错误区块、格式错误、承诺哈希不匹配、不交付、Evaluator错误批准/拒绝/离线等实验。错误付款场景即使配置为预期故障，Checker仍失败，避免将风险演示当成业务成功。

沿用左侧配置、右侧结果、实时耗时、加载状态、防重复点击、单步和暂停、手动出块、共享链锁、广播意图日志与对账。新增服务订单与交付物图节点，场景包和离线检查器支持新模板；原单Agent和peer_swap入口继续保留。

当前服务实验仅支持独立初态、固定参与方、固定实验价、实验TokenA/B及预设查询账户。报告区块由本次初始化结束时固定。不提供任意服务市场、任意Provider注册、A2A、x402、AP2或ERC8004，不宣称ERC8183完整兼容。Windows x64已验证，macOS未出新增包。云端模型未实测，模型接口自动测试使用本地协议夹具。

使用步骤和故障实验见操作手册_V0.15.md；实际自动化结果见v015-service-results.json、v015-contract-results.json、v015-unit-tests.txt，浏览器与解压验收见v015-ui-results.json及v015-package-smoke.json。历史v014等报告作为历史或旧场景回归材料保留，应按内容判断覆盖范围。

重复运行中观察到Windows短暂文件占用，事件日志原子替换现增加有界重试；持久写入失败仍中止后续操作，不通过删除已提交日志绕过错误。新增两项故障注入单元测试。
