# V0.15.2 验证摘要

新增模块使用真实本地Anvil链、官方Permit2源码的本地部署、独立签名进程和不同钱包的第三方兑现。

- 新增链上及离线验证：16项通过，包括140/80复现、统一预算、20/21边界、许可重放、错误spender、跨会话、并发预留、许可过期、篡改检测。
- 新增HTTP检查：8项通过，包括来源与凭据检查、旧执行隔离、防重复支付、逐步与一键运行、脱敏证据导出。
- 新增GUI检查：9项通过，1项BLOCKED。原生Chrome下载在自动化环境中被取消；下载附件响应、自动保存、JSON查看/复制与离线回放分别通过。1440/1024/390像素布局已检查。
- 继承功能回归：66项自动测试通过；任务中心独立签名换币与五类旧模板通过；16项服务购买回归通过。
- 原V0.15服务保护清单11个文件保持哈希一致。旧control/scenario运行源码保持原样。

风险复现案例的业务预算检查应失败：实际140超过预算100。这不表示测试执行失败；测试断言的是能够如实检测超支。

本次新增路径为脚本软件限权EOA，不是原版V0.15.1漏洞证明，也不是智能账户session key或生产钱包安全验收。旧版NOT_FULLY_ACCEPTED及未完成验收事项仍保留。
