# V0.14.1 界面更新说明

本版将双 Agent 原子交易调整为 V0.13 风格的左右工作区。左侧包含场景参数、Maker/Taker 目标和模型输入、运行选项、初始化与启动；右侧显示当前运行、检查结论、Agent 成本、资产变化、业务消息、订单、交易、因果图和档案。

桌面宽度大于 900 像素时保持双栏，较窄窗口自动改为上下排列。Maker/Taker 配置在左栏纵向排列，右侧各结果卡片纵向展示，长地址和表格使用换行或局部滚动。

交易合约、Agent 调度、钱包、消息与检查器保持 V0.14 原实现。旧场景包可继续打开。docs 中 v014 前缀测试报告属于 V0.14 基线；v0141 前缀文件记录本次界面和重新打包验证。

使用方法：先关闭旧服务，完整解压到新目录，再双击 start.cmd。浏览器若保留旧页面请刷新。进入“双 Agent 原子交易”，在左侧配置运行，在右侧观察结果。
