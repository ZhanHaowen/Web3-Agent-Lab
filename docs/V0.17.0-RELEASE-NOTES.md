# V0.17.0 Research Beta 更新说明

- 发布版本：**V0.17.0 Research Beta**。
- package 版本：`0.17.0-beta.1`。
- 基础版本：V0.16.0 本地/API 双后端研究版。
- 本次重点：为“通过 Agent 支付的可观察轨迹推断任务、隐藏预算与采购策略”建立可运行、可核对的数据与评估流程。
- 使用与证据：[研究操作指南](V0.17.0-RESEARCH-GUIDE.md)、[测试报告](V0.17.0-TEST-REPORT.md)。

本版实现的是研究基础设施和攻击基线。构造数据管线正常、支付协议运行成功与隐私推断有效是三个不同结论，不能互相替代。

## 一、四项研究能力升级

### 1. 可观察轨迹与真实采购环境

新增证据综述、风险分析、趋势分析三类任务，使用可复现构造语料。它们共享发现、分析、核验能力的六个 lite/pro 服务；价格档位统一为 `10000/30000` 个六位精度代币最小单位，不用任务标签编码商户或价格。规则策略或真实模型按实际 HTTP 服务返回决定下一次购买；低价服务可能覆盖不足，失败也完整记录。

每次运行独立部署本地链环境，采集真实区块、交易、calldata、回执、日志和可解析支付。公开观察者只使用公开 RPC 重新采集，不从私有日志删字段拼出公开输入。使用链上秒级区块时间，分别记录交易广播者与经济付款者。

新增公开 `observer.json`、图 JSON、GraphML、节点/关系 CSV，以及浏览器节点查看和离线回放。研究者的原始事件、模型/工具返回、采购关联、私有真值与私有溯源图另行保存；公开导出不含不可见的任务边。当前公开支付解析覆盖成功的顶层原生资产转账和 ERC-20 形状的 Transfer 日志，尚未完整解码 EVM 内部原生资产转移。

支持同代币、同商户、同价格档位的真实背景付款插入。它们由独立测试账户和种子生成，属于受控顺序交错，尚非并发多任务，也不保证账户不可区分。

### 2. 任务推断与私有真值评价

研究者保存任务类别、实例、正确答案、实际服务结果与任务检查；攻击子进程只接收匿名测试样本 ID 和公开特征。训练/验证标签可以提供，测试真值只在预测结束后由父进程关联计算指标。

当前任务推断使用训练集标准化的最近质心分类器，输出准确率、Macro-F1、混淆矩阵、接受覆盖率、接受样本错误率和未知类别拒识。真实任务标签不等于任务一定可从付款中辨认；共享服务目录和价格正是为了避免把明显商户标签误认为新发现。

按实例、模板、模型或指定组切分，重复公开观察、克隆与共享实例不能跨训练/测试集合。模型身份依据权重哈希或服务商/模型标识，温度、种子、端口变化不会伪装成不同模型。失败和未知运行保留，提供空特征与打乱标签负对照。

### 3. 隐藏预算与预算推断

私有总授权预算与公开钱包初始余额分别设置。账本按“已结算 + 预留 − 已确认退款”计算预算占用，记录每次采购的剩余额度、交易关联与状态变化。HTTP 错误、未交付和停止执行不自动成为退款证明；batch 未使用本金返还不冲销已经消费的服务成本。

推断目标是**总授权预算上限**，不是将钱包余额或已花金额改名为秘密。当前采用 kNN 邻居中位数及验证集绝对误差校准，输出 MAE、经验区间覆盖率、平均区间宽度和常量中位数基线。没有足够校准样本时区间上界明确为空；相同可见特征不能假装精确恢复不同预算。

账本有每步剩余预算，但本版攻击器尚未实现剩余预算曲线、子 Agent 分配恢复或主动报价探测。

### 4. 采购策略与策略推断

内置三种策略：成本优先采用便宜服务，质量优先选择高覆盖服务，自适应策略根据实际返回结果补买或升级。支持规则基线与真实本地/API 模型调用，不使用静默规则回退替代失败的模型决策。

策略推断采用与任务分类相同的分类及拒识流程，报告对配置策略标签的可区分程度。脚本策略具有明确规则；LLM 标签表示用户指定的策略，当前尚无独立判别器证明模型实际遵循该策略，不能宣称恢复了模型的全部内部思考。

公开特征包括交易/付款数量、商户频次、分资产金额合计、相邻商户转移、付款跨度/间隔与同块次数。金额、顺序、时间、商户、钱包特征可通过代码接口开关做消融；尚非深度时序模型或图神经网络。

## 二、六种实际可运行的支付部署

| 配置 | 本地已实现内容 | 不包含的能力 |
| --- | --- | --- |
| `x402-exact` | 固定官方 SDK、HTTP 402、EIP-3009 授权、验证与 ERC-20 真实结算 | 其他链、全部 x402 schemes、该路径的 Permit2 支付 |
| `x402-batch` | 固定官方 batch-settlement、voucher、通道注资、累计结算、未使用本金退款 | 跨进程自动恢复、全部生产部署及隐私保证 |
| `ap2-x402-exact` | 本地 ES256 mandate 与 exact 绑定，核验主体、金额、资源、链、代币、期限和重放 | 完整凭证签发/SD-JWT 生态认证、分以下金额 |
| `ap2-x402-batch` | 同样的本地授权子集与 batch 结合，包含累计额度约束 | 全部 AP2 商业接入和通道崩溃恢复 |
| `mpp-evm-charge` | 官方 mppx HTTP Payment challenge、凭证/回执，本地 settler 执行 EIP-3009 转账 | Tempo session、卡支付、外部商户和 MCP 扩展 |
| `erc8183-core` | 本地 client/provider/evaluator 任务托管，交付、确认、拒绝和到期退款 | hooks、费用、ERC-2771 和 Virtuals ACP SDK 互操作认证 |

x402 固定版本为 2.30.0，mppx 为 0.18.0，支付适配 viem 为 2.57.4，OpenZeppelin 为 5.6.1；依赖与原有框架依赖隔离。batch 标准地址使用 Anvil `setCode` 安装官方运行时代码，来源与哈希写入 manifest，不宣称生产 CREATE2 部署经过验证。测试 token 允许实验性 mint，不用于真实资产。

L402、UCP、OpenAI/Stripe ACP、Visa TAP、Mastercard Agent Pay、Nevermined、KYAPay 和 Virtuals ACP 只在协议清单中，尚不能执行。账户能力、身份协议、工具传输与支付结算分层记录，不因名称在清单中就视为兼容。

本版可比较已适配支付部署的可观察信息，但未实现地址轮换、金额隐藏、随机延迟或 PrivateX402/A402/TACEO 隐私协议。批量结算本身并不证明任务、预算或策略已得到保护。

## 三、原有功能受影响情况

本次采用新增研究模块和兼容桥入口。保留原页面、操作方式及证据读取器，不要求将原任务迁移为采购研究任务。原单 Agent 五类任务、双 Agent 换币、服务购买及跨路径预算已纳入本次 Windows 回归，在记录的范围内未发现退化。具体用例、构建和数量见[测试报告](V0.17.0-TEST-REPORT.md)。

新增的有意操作约束：研究运行期间禁止切换或停止共享本地模型，以免改变实验条件；共享推理服务仍可能产生资源竞争，本版没有性能无影响保证。

| 原有能力 | 本版处理与验证边界 |
| --- | --- |
| 查询、转账、授权、兑换、兑换后存入 | 入口保留，五类核心任务回归；旧工具继续接受人类可读数量 |
| 任务/Agent 中心、独立 worker、双 Agent 换币 | 入口与架构保留，独立 worker 及换币流程回归；不承诺大规模并发 |
| Buyer/Provider 服务购买 | 原模块保留，并对既有服务购买用例回归；不是自动迁移到 ERC-8183 研究适配器 |
| 跨路径预算与 Permit2 | 原模块及原签名路径保留，核心、金额边界、主服务和 HTTP 集合回归 |
| API / 本地 Qwen 双后端及原生采集 | 保留后端和记录模块；真实 Qwen 任务仍存在失败，不把管线通过算作模型完成 |
| 旧数据、原回放与高级控制 | 读取入口保留；未完成全部旧数据库迁移、所有历史包和高级控制组合的验收 |
| Mac | 源码入口保留，未完成 V0.17.0 Mac 真机验收 |

新增研究页面的金额单位与旧单 Agent 工具不同：研究配置填写六位精度**最小单位整数**。例如 `150000` 为 `0.15` Token；旧 `approve_token` 仍按原工具说明接收人类可读数量。两者不能相互套用。

## 四、开始使用与复查

1. 将完整 Windows 运行 ZIP 解压到新目录，双击 `open-research.cmd`；原平台仍可用 `start.cmd`。
2. 首次选择 `x402-exact`、规则自适应、难度 3、种子 42、预算 `150000`、初始余额 `1000000`、最多 12 步。
3. 核对付款状态、交付结果、任务断言与记录完整性，分别下载公开观察者包和研究者私有完整包。
4. 在离线观察者页加载公开包，查看图节点；该页不调用模型或 RPC，也不接受私有完整包。
5. 积累不同实例后运行推断评价，保留成功和失败。GUI 的至少 5 份限制只是入口下限；分组后样本不足的警告、无上界区间和未知类拒识不能忽略。
6. 用 `stop.cmd` 停止完整平台。停止新决策不撤销已广播支付；Unknown 需核对原回执，不能盲目重付。

批量运行和源码构建命令见[研究指南第 7 节](V0.17.0-RESEARCH-GUIDE.md#7-cli-与源码复现)。便携包不含 Qwen 权重，源码 Source code ZIP 不含完整便携运行程序。

## 五、验收解释与当前限制

本版测试覆盖真实支付、异常路径、观察者输入边界、数据分组、推断计算、便携运行和原功能回归，完整证据见[测试报告](V0.17.0-TEST-REPORT.md)。构造数据集和少量本地模型运行仅证明流程可运行与错误可留存，不能据此报告稳定的隐私攻击效果。

- 当前观察窗口由研究者给出；未自动从长期混合交易中定位任务或建立跨任务归属。
- 攻击子进程是输入隔离，未提供操作系统层的文件访问沙箱。
- RPC 数据没有共识或 receipt-inclusion 证明；检查器核对保存的账本及公开引用，不是所有支付语义的形式化证明。
- batch 通道内存状态不能跨进程自动续跑；未知支付保留占用与证据，不自动重复扣款。
- `windowGasUsed` 包含整个公开采集窗口的部署和背景交易，不能视为 Agent 的净执行 gas。
- 模型输出、签名、交易哈希与区块时间不保证逐字节复现；固定种子只约束构造语料与矩阵调度。
- 无生产网络、商用支付网络接入或全模型兼容承诺；本版实测平台为 Windows x64。

相关上游规范与实现入口：[x402](https://github.com/x402-foundation/x402)、[AP2](https://ap2-protocol.org/ap2/specification/)、[mppx](https://github.com/wevm/mppx)、[ERC-8183](https://ercs.ethereum.org/ERCS/erc-8183)。本版兼容声明以上述部署配置、固定依赖和保存的本地实测范围为准。
