# V0.18.0 测试网基础任务：操作与范围

V0.18.0 Testnet Beta（package `0.18.0`，prerelease）在原平台上新增独立页面 `/testnet.html`。首页“选择实验环境”可进入本地 Anvil 或公开测试网。原首页、任务与 Agent 中心、服务购买、跨路径预算及采购支付隐私研究仍使用原有本地环境；选择测试网不会把这些功能全局切换到公网。界面保留“基础任务预览”字样，表示开放的执行范围。

更新内容见[发布说明](releases/V0.18.0.md)，构建和测试身份见[验收报告](TESTNET-VALIDATION-REPORT.md)。

## 当前开放的功能

- 六个可选 EVM 环境：Base Sepolia、BNB Smart Chain Testnet、Arbitrum Sepolia、OP Sepolia、Polygon PoS Amoy、Avalanche Fuji C-Chain。其余十四个网络只列入候选目录，不能通过更换 RPC 开放写入。
- 五类基础任务：查询 TokenA 余额、向指定 recipient 转账、设置 AMM 授权、LabAMM 兑换、兑换新增 TokenB 后存入 LabVault。
- 脚本基线、兼容 API 模型、本地 Qwen3 4B；任务输入、允许工具、系统提示词、工具返回替换和两处暂停。
- 独立结果检查、原始事件、调用参数及结果、交易回执、可获得的内部调用、溯源图、完整 JSON 实验包及离线回放。

LabAMM / LabVault 是平台自有研究合约，不等于调用 Uniswap、PancakeSwap 等第三方测试 DEX。公开测试网预览的自动测试使用标准 RPC 连接隔离 EVM，不代表已经在上述六个公网逐笔成交验收。公开链不支持本平台的快照恢复、重置或人工出块；所有测试网任务继承当前状态。

六个可执行配置的 chainId 分别为：Base Sepolia `84532`、BNB Smart Chain Testnet `97`、Arbitrum Sepolia `421614`、OP Sepolia `11155420`、Polygon PoS Amoy `80002`、Avalanche Fuji C-Chain `43113`。目录中其他网络（包括 Ethereum Sepolia）在本版都未开放执行；不能用替换 RPC 的方式绕过配置白名单。

## 升级与启动

从 [V0.18.0 Release](https://github.com/ZhanHaowen/Web3-Agent-Lab/releases/tag/V0.18.0) 下载 `Web3-Agent-Lab-V0.18.0-Windows-x64.zip`，与旧版本分目录解压。先正常停止旧平台，保存原数据和导出包，再双击新目录的 `start.cmd`。GitHub 自动生成的 Source code ZIP 不含便携运行程序，应按 README 的源码开发步骤安装和构建。

新增运行写入该实例 `LAB_DATA_DIR` 下的 `testnet/` 子目录（默认 `data/testnet/`），不会自动迁移旧数据库。不要将旧数据目录中的钱包文件当作可公开分享的实验包。本版未全面验证任意历史数据库迁移；保留旧目录便于独立复查。

## 1. 连接环境

Windows 运行包请解压到较短路径，例如桌面一级目录。嵌套过深时 Windows 解压工具可能触发路径长度限制；V0.18.0 已在短目录完成无 `node_modules` 解压启动及 6/6 便携检查，具体构建身份和范围见测试报告。

1. 启动平台，在首页点击“公开测试网 · 基础任务预览”。保持使用本机平台地址。
2. 选择网络，填写对应 HTTPS RPC。平台核验 chainId，不能仅靠名称假定已连对网络。
3. 只读连接时不填私钥，填写观察账户；执行写入时填写专用测试钱包私钥及另一个 recipient 测试账户。自行准备原生测试 Gas；平台不自动领币。
4. 点击“连接并核验网络”，确认 chainId、账户、Gas 余额和权限。私钥输入框会清空，签名凭据只保留在当前服务内存；断开后该连接不再具有签名能力。已知敏感字符串的脱敏字典在服务生命周期内保留，这不是内存安全擦除机制。刷新页面不会把密钥存入浏览器。
5. 确认数允许 1–64，用于判断入链深度，并非 L2 已达到 L1 最终性保证。公开 RPC 受限或短暂失败时，界面会展示错误；不要将请求失败理解为网络停用。

每个运行实例请使用专用测试钱包。交易串行锁仅在当前平台服务进程内生效，不协调另一平台实例或外部钱包发起的交易；外部并发写入会改变 nonce 和初态，影响实验归因。

只读连接不需要私钥，但余额任务仍需要已校验的实验合约清单。写入要求测试 Gas、实验 TokenA 和正确的合约部署。

## 2. 准备 Lab 合约

没有部署时，勾选“本次明确部署自有 Lab 测试合约与实验资产”，再点击“部署 Lab 实验环境”。此操作发送多笔部署和初始化交易；等待结果后导出清单备份。

已有部署时，使用“导入清单”。服务端核验网络、账户和合约身份后接入。清单是配置和部署证据，不含私钥；不能将它理解为钱包备份。

如果部署遇到超时或网络中断，使用“只读对账 / 恢复准备”查询已有交易哈希。它不会重新广播交易；对账确认交易已成功或回滚并解除未决锁后，可再次显式点击部署继续准备。长期找不到交易或被外部同 nonce 交易替换时，当前预览不会自动解锁，也不提供自动替换、取消或丢弃恢复。找不到交易不代表未付款；不要更换账户或创建另一套部署来掩盖未决交易。

## 3. 运行任务

选择基础任务，填写人类可读代币数量。例如授权 20 TokenA 填 `20`，不要填 `20000000`。本预览固定启用目标金额校验。修改数量后点击“按参数重建任务输入”；自定义输入与结构化目标冲突时，服务端拒绝创建运行。

选择执行方式：

- **脚本基线**：验证钱包、工具、交易及检查流程，没有真实模型调用，不应作为 LLM 实验样本。
- **兼容 API**：填写服务地址、模型 ID 和 API Key，使用支持工具调用的 Chat Completions 服务。API Key 不进入实验包或浏览器存储。
- **本地 Qwen3 4B**：先到“本地模型管理”准备模型。模型在本地推理，公开测试链仍需网络连接；模型不可用时不自动回退远程 API。

后端可调用不代表模型能稳定完成所有任务。历史同功能候选的 Qwen 五任务采集/离线检查为 5/5，任务完成为 4/5，“兑换后存入”未完成；原采购研究补测为 0/3 任务完成。失败保留在证据中，不能仅凭 Agent 的文字答复判为成功。API 接口的自动回归使用本地协议 fixture，未代表任何商业模型端到端验收。

允许工具和系统提示词用于设置实验范围。工具返回替换 JSON 只改变 Agent 看到的结果，原始返回和实际链上效果仍需保留。工具前暂停与交易提交前暂停可在下一安全检查点查看待执行操作；“停止后续操作”不会取消已经广播的交易。

暂停事件写入期间可以继续或停止；工具/交易必须等待相关事件记录完成后才继续。记录失败、写记录期间取消均不得继续提交交易。连续点击“继续”不会授权第二次提交，后续操作是否还有暂停点由任务流程决定。

## 4. 查看结果与轨迹

当前实验同时显示链上状态和独立任务结论。链上交易成功不保证任务成功；`pending` 是等待确认，`unknown` 是现有证据不足，二者都不能当作失败或未付款。

当前核验会扫描本次任务的区块窗口，窗口超过 1000 个区块或 RPC 无法提供所需历史数据时，会保留 `unknown`。快出块网络中的长时间模型运行可能触及此上限；不要把证据不足改标为成功。

扫描前后会检查链上锚点，遇到重组或缺失证据按 `unknown` 处理；离线复查不能将这类原始未知结果升级为成功。成本中的执行 gas 按 `gasUsed × effectiveGasPrice` 计算，不能直接当作 L2 包含 L1 数据费在内的全部网络费用；原始回执字段用于另行分析。

点击原始事件可查看模型请求/响应、工具参数/返回、合约调用、交易参数、回执及原始文件引用。运行封存后点击“加载完整封存证据”，再点击图节点查看显式关联和来源事件。内部 EVM 调用取决于目标 RPC 的调试追踪能力，缺失时不根据相邻日志补造关系。

“更新链上结论”只采集新链上证据并追加检查结果，不重新调用 Agent。“按封存证据复查”由本机服务根据保存的证据重新计算任务结论，不请求链或模型。“校验原始记录”只验证文件完整性；哈希一致不证明来源可信，也不替代任务检查。这三个操作用途不同。

## 5. 下载与离线回放

完整 JSON 实验包包含原始 `config.json`、`events.jsonl`、`blobs/`、`manifest.json`，以及独立的 `derived/` 派生文件。可以分别下载图 JSON、GraphML、节点 CSV、关系 CSV、详细执行轨迹和展开事件 JSONL。未封存或缺失的文件不会被界面虚构补齐。

导入完整 JSON 实验包后，页面立即停止轮询并禁止在线 API、模型及链请求，执行原始文件 SHA-256、字节数、实验编号和事件引用校验。有效派生图另核验派生清单；缺失或损坏的图不作为已验证关系显示。支持从头回放、下一事件、显示全部和节点来源检查。回放只是读取记录，不是恢复链状态重新实验。

点击“返回在线界面”才恢复连接服务器。公网重跑应新建一次连续实验，保留初态差异与新的实验编号，不能承诺得到相同结果。

## 6. 原有功能受影响情况

首页新增环境入口并加载少量布局样式；原 `app.js` 未重写。本地初始化、重置、快照、单 Agent、独立 Agent、预算及研究页面保留原入口和环境语义。测试网页使用独立 `/api/testnet/*` 接口、会话令牌与实验目录，不复用本地链的管理按钮。

测试网执行与原单 Agent / 任务中心的写入通过运行协调锁互斥；独立预算和研究链仍各自管理，并非所有模块共享全局锁。这不把本地实验环境替换成公开链。新增页面不宣称现有全部研究模块已经多链化。

原研究模块另修复 Windows 短暂文件占用导致的账本原子替换失败：只对已写好的临时文件做有限重命名重试，不重试采购、付款或预算变更；错误耗尽后仍报告失败。

## 验证方式

便携包运行已构建程序不需要安装开发依赖。若需要重新编译和运行完整测试，请先按 [README](../README.md#源码开发) 的开发步骤安装固定 Node、pnpm 和锁文件依赖，并完成 `pnpm run setup:research`；随后使用仓库固定 `runtime/node.exe scripts/testnet-regression.mjs`，为 `LAB_REGRESSION_OUT` 设置新的输出目录。该运行器使用 Git 基线信息，应在本地 Git 工作副本中运行。Windows 启动器阶段还需要运行包中的匹配运行文件；普通源码克隆不自带这些文件。

`node --test tests/testnet-ui.test.mjs` 验证金额、模型配置、离线网络隔离、证据完整性、图缺失处理、事件点击及输入安全。可选浏览器测试 `node tests/testnet-browser.mjs` 需要设置 `TESTNET_PLAYWRIGHT_MODULE` 与可选 `TESTNET_BROWSER_PATH`，使用隔离 EVM fixture，产物存于测试 artifact 目录；不会向公网广播交易。最终是否可用于某条公开链，应另完成该网络的专用钱包、Gas、部署和五类任务逐项验收。
