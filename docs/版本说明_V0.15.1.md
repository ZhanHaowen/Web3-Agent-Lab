# V0.15.1 版本说明

V0.15.1 是针对《V0.14 增量实现方案与验收标准》修订 2 的规范修订预览版，状态为 **NOT_FULLY_ACCEPTED**。完整 AT-01 至 AT-36 尚未全部验收通过；本版不能表述为正式完成全部标准。

本次修改原 V0.14 的任务管理和双 Agent 原子换币路径，保留后来 V0.15 增加的购买 Agent 服务。服务购买相关的 11 个受保护文件逐项哈希匹配，包括服务模块、共享场景模块、服务界面、合约与合约产物；这项文件级核验仍需结合整包回归阅读。

## 任务先发布，Agent 独立上线

新增任务中心，将 TaskDefinition、已发布 Job、具体 Execution 和 Agent 配置分开。发布任务不要求 Agent 或实验链已经启动；可先保存任务，再分别启动 Agent 并分配角色。在线状态、能力授权、钱包占用与角色确认通过后，同链任务进入执行队列。

Agent A、B 使用独立进程、钱包、身份与会话。钱包秘密由各自进程读取和签名，控制端管理调度、意图持久化、交易广播与对账。钱包、模型配置和控制身份分文件保存；管理员会话与 Agent Bearer 权限分离。

六类固定模板具有版本目录：查询余额、转账、授权、兑换、兑换后存入、双 Agent 原子换币。前五类在新任务中心当前使用脚本适配；原单 Agent 页面继续保留模型实验。双 Agent 换币支持脚本与两个独立模型会话，可使用相同的 API、模型和 Key。

## 资金状态与停止后的处理

运行状态、业务结果和资金结果分别展示。停止决策不会自动退款或撤回已广播交易；Open 订单、Pending/Unknown 交易和无法确认的资金状态会保留环境锁，需显式对账、取消或到期清退。

活跃 V2 执行正常关闭控制服务时，保存执行与链环境信息，并保留原实验链供再次连接和核对。重新打开时仍须核验链身份和合约，不把新链当作原链续跑。未知交易或记录失败不能被当作安全结束。

执行完成后增加 `finalizing` 可见状态：先完成证据归档与角色租约释放，再向用户发布可安全使用的终态，避免页面已经显示结束而下一任务仍遇到未释放锁。

Agent 重启时先恢复注册与心跳。持久化 outbox 中的旧执行事件等待角色重新绑定后再补投，并保留原事件身份；不会因旧租约待确认事件而立即丢失在线状态。具体崩溃点的可靠性仍以对应构建的恢复测试为准。

暂停提交门的补充实验曾发现：页面可见 paused 时，恢复门可能尚未建立。此问题通过新的 RemoteScene 路径单独修补和复测，保留 V0.15 原 Scenario 实现。是否消除该竞态，以最终 r3 暂停、继续及关闭恢复证据判定，不以早期正常示例替代。

## 证据、图和离线复核

任务中心继续采用左侧输入、右侧结果的布局，显示耗时、双方状态、工具与交易记录。完整执行图改为 SVG 三泳道，按角色与 Agent 身份布局，只绘制已记录的关系；节点和连线均可查看原始事件与负载。可下载图 JSON、GraphML、节点 CSV 和关系 CSV。

新增 Job、Execution、身份绑定与来源流记录；交易准备与签名提交接口已经实现。可用 doctor 核对本机运行条件和 V0.15 保护文件，用 verify、replay、check 离线检查导出包。离线哈希核验检查包内一致性，不证明采集者诚实，也不替代实时链查询。

固定提交的 42 个基线文件已取回并与旧构建清单匹配，其中 12 个为原始 TypeScript 源文件。新增运行时仍为 ESM；严格接口类型检查只覆盖指定接口和类型测试。

## 当前验证与未完成范围

单元测试、原功能回归和服务购买回归已有独立记录。最终数量、构建哈希及 r3 复测结果见 [最终验证摘要](最终验证摘要_V0.15.1.md) 和相邻验收 JSON/CSV。较早 core-r2 没有 FAIL，不代表各项完整子条件已经通过；历史报告不能直接累加为最终验收。

最终复测入口见 [验收证据阅读说明](验收证据索引_V0.15.1.md)。其中 r3 目录只在报告实际存在且 buildHash 匹配交付构建时有效；缺失报告代表仍缺该轮证据。

当前必须明确的缺口包括：

- 完整运行时 TypeScript 迁移和第三方干净全源码构建尚未完成；严格接口类型检查不能替代。
- 真实模型 10 次完整尝试尚缺证据，模型协议夹具不能代替。
- Apple Silicon macOS 原生发布和实机验证尚缺证据。
- GUI 实测因 ComputerUse 无法可靠识别和确认当前 URL，相关浏览器交互、双尺寸及干净用户体验验收明确保留 BLOCKED；静态 DOM 检查不能替代。
- 独立人工核验和签字、未运行的恢复与对抗子条件，按最终验收表保留 BLOCKED 或实际状态。

## 使用与升级

将本包完整解压到新目录，先备份旧版数据。运行 start.cmd，再运行 open-task-center.cmd 打开本实例任务中心。已有服务购买继续从原入口使用，不需迁入新任务中心。

发行包不携带 data* 运行目录、build 诊断目录、私有工具或用户凭据；运行后生成的数据库、钱包配置和模型配置应单独保管。操作步骤、备份与资金收尾方法见 [V0.15.1 操作手册](操作手册_V0.15.1.md)。
