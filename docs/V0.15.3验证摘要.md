# V0.15.3 验证摘要

本次主要变化：

- 分类名称与页面标题不绑定特定数字。
- 选择分类不重置金额；显式生成根据当前预算、首笔支出和偏移量计算，修改后重新标为自定义。
- 页面和接口接入主服务，导航使用相对地址；只运行start.cmd即可访问，stop.cmd统一清理。
- 原任务链保持隔离，预算模块不改写主进程环境配置。
- 启动中关闭、签名后未兑现时关闭均检查了所拥有进程的退出。

验证范围：

| 项目 | 结果 |
|---|---|
| 自动测试（原66项 + 分类生成10项） | 76通过 |
| 预算核心回归 | 16通过 |
| 任意金额、小数与最小单位矩阵 | 9通过 |
| 同源主平台、原链隔离及停止竞态 | 9通过 |
| 实际start.cmd/stop.cmd启动与关闭 | 3通过 |
| 请求鉴权、幂等推进及导出 | 8通过 |
| 桌面/窄屏/手机、参数交互及离线回放 | 11通过，1项原生下载受环境限制 |
| 原独立签名换币及五类旧任务 | 6通过 |
| 服务购买回归 | 16通过 |

不同表项覆盖范围可能重叠，不将数量相加作为完整标准验收数。

GUI测试使用真实主平台地址，覆盖预算250/首笔90/偏移25生成第二笔185，分离策略实际275、正常计数90；同一配置统一策略拒绝第二笔；边界分类生成160。额外链上矩阵覆盖大额、不同预算、小数和六位精度。

本机自动化Chrome仍取消原生下载，附件响应、自动保存、查看/复制JSON及离线读取已验证，不将原生下载标为通过。
