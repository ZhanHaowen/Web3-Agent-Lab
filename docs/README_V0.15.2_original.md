# Web3 Agent Lab V0.15.2 · 跨路径任务预算研究版

在 V0.15.1 基础上新增独立预算实验入口，真实复现“正常交易 80 + Permit2 签名兑现 60，总支出 140，正常入口计数仍为 80”。同时提供统一预算防护和边界对照。

## 立即复现

1. 将 ZIP 完整解压到新目录。
2. 双击 **start-budget-lab.cmd**。不需要先启动原任务中心，不需要模型 API Key。
3. 保留默认预设，点击“一键运行”。
4. 应看到：初始 200、任务预算 100、正常计数 80、实际支出 140、最终余额 60、超支 40。
5. 选择“防护：统一预算 · 80 + 许可 60”，再运行。应拒绝许可，实际支出 80、最终余额 120。
6. 若想看清每一步，点击“初始化并逐步观察”，再依次执行支付、签名、第三方兑现、独立检查。

详细说明：[V0.15.2 操作手册](docs/操作手册_V0.15.2.md)。

## 证据与研究边界

这是新增研究适配器中的故意分离计数配置。不能据此声称原版 V0.15.1 存在 Permit2 漏洞，也不是 Permit2 本身失效。对照组共同预算在签名发出前预留最大可兑现额度。

Agent 的 EOA 私钥只存在独立签名进程的内存中。两条路径绑定同一执行、会话和钱包。兑现者另持独立钱包；实际兑现使用官方 Permit2 合约本地部署，不模拟余额。

新增实验为脚本模式，限制由软件签名器执行；不声称智能账户会话密钥、链上全局预算或生产安全保证。新增服务和专用临时链与原任务中心分离，不接管原中心角色租约，不支持中途恢复。关闭服务会销毁临时链。

证据包自动保存为 data-budget/执行ID.json，也可通过页面下载或查看/复制 JSON。浏览器若阻止下载，使用自动保存文件或复制入口。随包 examples/budget/ 有已运行示例。

## 原有功能

原入口 start.cmd、open-task-center.cmd、单 Agent、原子换币及购买服务继续保留。原版说明见 [V0.15.1 原 README](docs/README_V0.15.1_original.md)。旧版未完成验收事项不会因本次新增自动变为通过。

新增实验默认 http://127.0.0.1:4319；停止使用 stop-budget-lab.cmd。原任务中心默认 4317，独立启动/停止。新增实验链自动选择空闲端口，不重置已有链。

实际验证见 docs/v0152-budget-results.json、docs/v0152-http-results.json、docs/v0152-gui-results.json 及 docs/V0.15.2验证摘要.md。
