# V0.16.0 本地模型与双后端操作指南

## 1. 准备文件

本版保留 API 模式，同时加入平台托管的 Qwen3 4B。本地模型是 Agent 的推理组件，工具权限、链、钱包、结果检查器仍由平台统一管理。

- 模型：Qwen3-4B-Instruct-2507 Q8_0，文件大小 **4,280,404,960 字节**（约 3.99 GiB）。SHA-256 为 `af6e43ab13611311226e6f809f6a39b1a87b6df613bbf79468059f92ce819c4a`。这不是其他量化版本的通用摘要。
- 推理引擎：官方 [llama.cpp b12019](https://github.com/ggml-org/llama.cpp/releases/tag/b12019)。Windows 使用 x64 Vulkan 包，保留同目录 DLL。macOS 使用与本机架构匹配的原生包；本次未完成 Mac 真机验收。
- 固定模型、来源及许可见 `src/local-model/assets.json`。Git 与普通源码 ZIP 不含约 4.28 GB 的模型文件。内存需求高于文件大小，并随上下文/GPU 分配变化。
- 所有实验使用本地测试账户和测试代币。平台运行数据目录默认 `data/`；自定义启动时用 `LAB_DATA_DIR`。模型可以保存在其他盘，不需要复制到每个实验包。

## 2. 启动与导入

已有 Windows 便携包时双击 `start.cmd`。源码安装先按[构建说明](third-party-rebuild.md)完成固定依赖与 Anvil，再运行 `pnpm start`。浏览器进入平台，点击“本地模型”，或打开同源 `/local-model.html`。

本次 Windows x64 发布 ZIP 已附带 Node、Anvil 和 `runtime/llama-b12019-vulkan/` 推理引擎。解压后选择其中 `llama-server.exe` 的绝对路径；模型权重仍需单独导入或下载。请完整解压，不要只从 ZIP 中拖出一个 EXE。该 ZIP 是便携运行包，不是安装向导，也不包含旧实验或本机秘密。

Windows 建议解压到短目录，例如 `C:/Web3Lab`，避免多层中文目录或重复套入完整版本名。包中保留了部分文件名较长的历史验收资料，在未启用长路径支持的机器上，过深的目标目录可能触及约260字符的路径限制。遇到解压报错时换短目录重新完整解压，不要忽略缺失文件后直接启动。

在管理页填写模型文件和 `llama-server.exe` 的绝对路径；勾选首次导入运行时指纹。模型 SHA 固定，运行程序及邻近依赖库在显式导入时计算 SHA，启动前重新校验。导入本地 SHA 用于识别文件，不等同于供应商签名验证。

保存配置后点击启动。首次读取 4 GB 文件校验需要时间。只有状态为 ready 后才能推理。默认端口 8495、上下文 16384、最大输出 768、6 个线程、1 个推理槽、GPU 自动分配，禁用 reasoning 输出。可以在管理页调整这些设置，保存后需重新启动。端口已被其他程序占用时会拒绝接管，不会杀掉其他服务。

也可离线导入（平台未启动时执行，路径替换为本机实际值）：

```powershell
node scripts/setup-local-model.mjs --import-model "D:/models/qwen3-4b-instruct-2507-q8_0.gguf" --server "D:/llama-b12019/llama-server.exe" --data-dir "./data"
```

尚无模型时，显式下载固定权重；支持中断续传和完整 SHA 校验：

```powershell
node scripts/setup-local-model.mjs --download-model --model-dir "./models" --server "D:/llama-b12019/llama-server.exe" --data-dir "./data"
```

下载需要联网；之后本地模型、本地链和本地工具可以离线运行。真实主网分叉、外部工具或 API 后端仍需要其对应网络服务。引擎不自动安装，完整参数见 `node scripts/setup-local-model.mjs --help`。

便携包用户在包根目录执行上述命令时，可把 `node` 替换为 `./runtime/node.exe`，无需另装系统 Node。例如使用内附引擎下载并导入模型：

```powershell
./runtime/node.exe scripts/setup-local-model.mjs --download-model --model-dir "./models" --server "./runtime/llama-b12019-vulkan/llama-server.exe" --data-dir "./data"
```

先完成导入，再双击启动平台；若平台已启动，则在 GUI 内保存相同模型/引擎路径并启动服务。预留至少模型大小之外的运行、实验数据和解压空间；实验量大时优先把模型与数据放在容量充足的盘中。

## 3. 选择后端并运行

单 Agent 页面选择模型模式，再选择“本地 Qwen3 4B”或“API”。本地不填写 Key 和远程 URL；API 模式继续使用兼容 Chat Completions 工具调用的地址、模型 ID 和 Key。不要把 Cursor 账户管理 API Key 当作通用模型推理 Key。

独立 worker 为重启复用配置，会把 API Key 写入本机 `data/agents/<id>/model-secret.json`；该文件不是加密凭据库。请保护数据目录，不把整个 data 目录作为数据集分享。实验导出和发布打包会排除这些秘密文件，模型事件中的已知 Key 会脱敏。本地后端不需要这些 Key。

原有余额、转账、授权、兑换、兑换后存入任务保持不变。先初始化链，选择任务、独立或连续实验模式后运行。脚本基线仍单独保留；选择脚本不会启动本地模型。金额继续传人类可读十进制字符串，例如 20 个 TokenA 填 `"20"`，不填最小单位整数。

双 Agent 场景与服务购买页按角色分别选择后端。任务中心创建独立 worker 时保存该 Agent 的后端配置，再启动进程、发布任务、分配角色并执行。当前任务中心五种原任务模板仍是脚本适配；单 Agent 模型实验使用原实验入口。服务购买仍使用原场景架构，不宣称已迁移为独立 worker。

本地推理服务可由多角色共享，角色上下文与成本独立；默认单槽按请求处理，不承诺并行吞吐量。更换配置或停止服务前，结束实验并停止使用本地后端的在线 worker；旧 worker 不允许继续用新运行时冒充原模型身份。

提示词、温度、步骤数等保留在实验配置。高级调用 API 可显式传 `topP`、`topK`、`repeatPenalty`、`seed`、`maxOutputTokens`，实际发送值进入 `model.request.body`。本地请求的最大输出不能超过运行时限制。建议按模型配置建立不同实验组，不把提示词调整前后结果混算。

## 4. 查看、导出与复查

运行详情中的模型原始证据面板可查看请求、响应正文及完整负载；下载证据索引和原始文件子集。完整实验导出保留 config、事件、内容寻址 blob、检查结论及派生图。模型产生错误或空工具调用时也导出原始记录，不用脚本代替模型补做任务。

原始 HTTP body 是接口收到的文本，可能因已知秘密脱敏而变化；`capture.redacted` 与正文 SHA 用于识别实际落盘版本。未提供的 token 数记为未知，不编造为 0。运行时日志以共享会话的字节范围保存，不能将其中所有行都解释为某一 Agent 独占产生的数据。

离线导入已导出的实验包，可查看轨迹、原生数据和关系图，不调用模型、不提交交易。命令行验证与复查：

```powershell
node dist/cli.mjs verify "D:/experiments/run.json"
node dist/cli.mjs replay "D:/experiments/run.json"
node dist/cli.mjs check "D:/experiments/run.json"
```

重新运行会恢复相应初态并再次推理，与离线回放不同。原模型/引擎/模板/运行时参数不匹配时拒绝将其当作原配置重跑。即使配置相同也不保证模型输出逐字节一致。连续模式的旧运行仍不能直接按独立模式重置复跑，需要恢复预存会话快照或开启新实验。

## 5. 常见问题

- SHA 不一致：检查是否拿错量化版本或下载不完整；不要改固定 SHA 来跳过验证。
- local 未配置/未启动：打开管理页显式导入并启动，失败不会自动调用付费 API。
- 端口被占用：换空闲端口，或由用户关闭占用者；平台只停止自己启动的模型进程。
- GPU/内存不足：关闭其他占用，降低上下文或改 CPU；更改配置后用新实验编号记录，不混用旧运行身份。
- 交易成功但任务失败：查看独立检查器、金额/授权及工具序列；链上成功不等于模型完成了用户任务。
- 4B 多步骤任务漏做或步骤上限：这是需要测量的模型行为，完整保留失败数据。可另设提示词/参数实验组，不能以自动补交易掩盖失败。
- 旧数据缺少原始 body 或本地模型身份：界面明确标记缺失，不补造；新格式不改变历史原始文件。
