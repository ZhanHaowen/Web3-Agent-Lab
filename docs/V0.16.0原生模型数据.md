# V0.16.0 原生模型数据约定

## 数据边界

采集的是平台实际发送、收到、执行和检查的数据。接口未返回的内部思维、隐藏状态和逐层神经网络张量不在数据范围内；本地运行不会凭空获得这些信息。模型成功、工具成功、交易成功和任务成功分别保存。

GUI 提交的任务/模型配置与服务器解析后的有效配置分开记录；原始输入保存在实验配置与事件中。这里的“前端数据”指实验配置、输入、工具可见结果和显示依据，不采集无关的鼠标移动、浏览器密码、其他页面或 Cookie。

API Key、助记词、私钥、会话/身份 Token 不进入实验数据。原始正文遇已知秘密或敏感字段会脱敏，因此“原生”并不意味着保存凭据。每个正文提供是否脱敏、实际保存文本的 SHA 和接口实际字节数，不把脱敏文本冒充未修改的网络字节。

## 模型事件

- `model.request`：`modelCallId`、`clientRequestId`、`attempt`、`provider`、`backend`、实际 endpoint、脱敏 headers、`request` 解析对象、`body` 实际 UTF-8 JSON 正文、`bodyComplete`、开始时间/超时与 capture 元数据。
- `model.response`：对应调用 ID、HTTP 状态、安全响应头、供应商 request ID（若有）、原始 `body`、解析结果 `response`、解析错误/finish reason、首字节/总耗时及 usage。
- `model.error`：超时、取消、网络失败、HTTP 错误或 JSON 解析失败；记录是否实际发起 transport。中途断流保留已经收到的正文前缀，并设 `bodyComplete:false`，不会用重构 JSON 代替原文。
- `capture.recordedBodySha256`：对最终脱敏、最终落盘的 `body` 计算 SHA-256。后续采集边界再次清理时重算，避免哈希仍指向清理前正文。
- `usage.status`：reported / partial / unknown / unavailable；未知计数为 null，不按 0 报告。累计成本只代表已知小计时用 `usageAccounting:known_subtotal_only` 标识。

一次失败的真实请求也计入调用量。worker 的成功和失败决策都持久化；对于已写入 checkpoint 的 command，重传或 worker 重启时重新投递已有结果，不再次推理。若进程在模型请求之后、决策持久化之前突然崩溃，不能保证模型请求恰好执行一次；交易另由原有意图与幂等机制控制。平台不隐藏重试，不从本地失败自动切换付费 API。

## 本地运行身份与运行时原文

`model.localRuntime` / 请求的 `backend.localRuntime` 保存固定权重 SHA、运行程序 SHA、邻近动态库 SHA、平台/架构、启动参数、上下文、输出限制、线程、GPU、ownerId/PID、`/props` 返回和实际聊天模板及摘要。`localRuntimeManifestPresent` 只表明存在元数据，可信托管身份由服务端的文件校验与进程归属检查建立。

`model.runtime_evidence` 将运行 manifest、props、生命周期 JSONL、stdout 和 stderr 作为自包含文件快照进入实验事件/内容寻址 blob。各文件包括角色、原始路径引用、源字节范围、内容的 base64 编码、保存后字节数及 SHA；先解码清理秘密，再编码和重算 SHA，避免 base64 绕过清理。

日志范围明确属于共享推理服务会话。单 Agent 可记录本次开始后的范围；多角色记录同一服务会话的快照，可能与其他实验重叠。不要把服务启动日志或共享调度行解释为特定 Agent 的独有因果证据。模型调用归属以 `modelCallId`、role/Agent/run/event 引用为准。

权重文件与引擎可执行文件不复制到每个实验包；包内保留固定来源、SHA 和完整配置，研究者自行取得相同字节。运行日志采集失败会显式产生记录不完整或失败，不宣称完整导出。

## 文件组织与离线使用

原单 Agent 格式继续使用 `config.json`、`events.jsonl`、内容寻址 blobs、`manifest.json`；多 Agent 使用 `raw/events.jsonl`、`raw/blobs/` 与 manifest。独立 worker 先进入持久 outbox/SQLite，再归档到实验包；JSONL 与 blob 是可分发的原始证据，不要求分析者使用运行时数据库。

`derived/` 保存独立检查、图 JSON、GraphML、CSV 与展开轨迹。GraphML 保留节点/边类型、角色、原始事件引用及完整记录，避免只剩图拓扑。旧数据缺少的原文/关系明确标记，不回填伪造字段，不修改历史 manifest。

研究者应保存完整实验包并运行 `verify`，再使用 `replay` 和 `check`。单独下载模型证据子集便于分析，但不能代替含链状态与检查证据的完整实验包。原始图或链上事件存在不等于证明模型推理正确。

## 复现元数据

必须同时报告软件 `sourceHash`、权重/引擎/模板 SHA、量化、硬件、运行参数、提示词、任务输入、工具定义、初始链状态和模型模式。相同 seed、相同 temperature=0 不保证跨硬件、运行时或调度的逐字节确定性。API 后端还需记录服务商和模型 ID；只能固定其接口可提供的版本信息。

本地模型能力评估与平台正确性回归分开报告。模型漏调用、错误授权或步骤耗尽是可分析结果；采集丢失、错误归因、哈希不一致或离线无法检查是平台缺陷，不能混算。
