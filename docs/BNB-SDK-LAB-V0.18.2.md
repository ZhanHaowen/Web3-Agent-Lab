# BNB SDK 实验室：V0.18.2 操作与范围说明

本版将 BNB Agent SDK 作为**独立实验对象**接入 Web3 Agent Lab。入口为 `/bnb-sdk.html`，使用独立运行子进程、独立实验编号和记录目录；不替换平台原有 AgentKit、LangGraph、模型后端或支付适配器。

固定 SDK 版本为 `0.6.1`，上游提交为 `260e16196931780d0370bd3a9d9b67ece744bb9d`。本页执行可核验的 SDK 脚本实验，**不调用大语言模型**。其中“Agent 身份注册”指链上身份登记，不表示启动了一个具有推理能力的 Agent。

## 1. 当前可运行场景

| 场景 | 实际执行 | 完成依据 | 边界 |
| --- | --- | --- | --- |
| x402 本地签名与预算 | 使用真实 SDK 和临时本地钱包进行签名、验签、预算及资产路由检查 | 保存的操作结果、验签结果及独立检查 | 不进行 HTTP 402 采购或链上结算；离线复查不重新执行签名 |
| 公开部署只读探测 | 读取 BSC 测试网 97 或主网 56 的区块、预设合约代码和代理实现信息 | 网络匹配、合约代码与读取结果 | 只读；合约存在不代表业务交易成功 |
| ERC-8004 分叉身份登记 | 从 BSC 测试网创建独立本地分叉，通过 SDK 注册身份并读回 | 本地交易回执、身份归属及登记信息 | 真实已部署合约字节码在本地执行，不是公网登记 |
| ERC-8183 分叉任务创建与取消 | 在本地分叉创建未注资任务，再取消同一任务 | 任务归属、零预算、状态变化及交易回执 | 取消 OPEN 任务不等于对已支付资金执行退款 |

完整注资、交付、结算、退款，真实 x402 HTTP 采购，以及 TWAK、Altana、Turnkey、代付服务均未开放。页面与结果记录会保留这些限制，不能将上述局部实验描述为全协议兼容。

## 2. 从界面运行一次实验

1. Windows 便携包先解压到较短目录（例如 `C:\Web3Lab`），避免旧版 Windows 长路径限制导致文件未解压完整。按原平台启动方式打开 GUI，在导航中选择“BNB SDK 实验室”。已有平台启动脚本和其他实验入口继续使用。
2. 首次使用可选择“x402 本地签名与预算”。该场景不需要 RPC、模型、API Key 或用户钱包私钥。
3. 需要链上合约实验时，选择“分叉身份登记”或“分叉托管任务创建与取消”，来源网络为 BSC 测试网。页面只提供内置公共 RPC 预设；可在 PublicNode 与默认节点之间选择。
4. 可选填固定分叉区块。不填写时记录本次使用的源区块；重做时可依据记录固定区块，但公共 RPC 必须仍能提供相应历史状态。固定区块不保证未来节点始终可用。
5. 设置 30–600 秒超时。勾选“每次操作前暂停”后，使用“继续当前操作”逐步推进；也可在运行时请求下一操作前暂停。界面显示可用控制状态。
6. 点击“开始独立实验”，查看运行状态、检查结论和原始事件。停止不会撤销已经完成的本地交易。RPC 不可用、运行中断或缺少证据会保留错误或未知状态，不计作通过。
7. 封存后可“重新检查记录”。这会重新核验已保存证据，不会重新发起交易，也不读取当前公开链来冒充原运行状态。

本页不接收自定义 RPC URL、私钥、模型 Key 或任意合约地址。公开主网只开放部署只读探测；本地分叉交易使用平台生成的临时实验账户。分叉期间需要访问源 RPC，但交易只发给本机 Anvil。

## 3. 查看调用关系与导出数据

点击事件可查看操作参数、返回结果、交易、回执和原始数据引用。溯源图展示“实验 → SDK 操作 → 合约 / 交易 → EVM 调用”等有明确证据的关系；节点与连线均可点击，原始事件引用可回跳检查。未调用模型时不生成模型节点；没有获得内部调用轨迹时不补造 EVM 节点。

封存后的完整实验包为 JSON，schema 为 `web3-bnb-sdk-bundle-v1`。包中 `files` 按相对路径保存原文件内容，并保留运行状态。界面另提供图 JSON、GraphML、节点 CSV、关系 CSV、详细轨迹、原始事件 JSONL 的单项下载。

| 文件 | 用途 |
| --- | --- |
| `raw/events.jsonl` | 原始事件索引、顺序与哈希关联 |
| `raw/blobs/<sha256>.json` | 内容寻址的原始操作参数、结果及证据 |
| `summary.json` | 版本、运行摘要、范围限制与结果 |
| `derived/checker.json` | 独立检查结果 |
| `derived/graph.json`、`derived/graph.graphml` | 派生溯源图 |
| `derived/nodes.csv`、`derived/edges.csv` | 节点与关系表 |
| `derived/execution-trace.json` | 展开后的详细执行轨迹 |

原始数据与派生数据分开保存。私钥、API Key 和可再次使用的付款签名不进入导出包；签名实验保留非敏感描述与实际验签结果。因此“完整记录”指该范围内的完整实验记录，不包含签名秘密。哈希检查用于检出记录变化，不等于外部可信时间戳或链上锚定。

完整实验包供实验人员内部核验，**不是严格隔离的攻击者视图**。不能直接拿该包作为支付隐私推断的攻击者输入；原有隐私研究入口仍负责其自身的信息投影和评估。

## 4. 离线回放与重新运行的区别

在本页导入已下载的 JSON 实验包后，页面停止轮询并取消在途 API 请求。导入只浏览存档和其中保存的检查结论，不在浏览器中重新计算哈希，也不证明来源可信；独立复核需要对原实验目录运行检查器，或在在线历史记录中点击“重新检查记录”。随后“从头回放”“下一事件”“显示全部”仅切换本地事件列表。调用图展示该记录的全量已有关系，不随逐条回放截断。图和原始文件缺失时显示缺失，不从文字结果推造关系。

也可以直接打开 `/bnb-sdk.html?offline=1`，从页面加载起不发起实验 API 请求，再导入实验包。此处“离线”指不访问模型、SDK 执行服务或链；HTML、CSS、JavaScript 页面资源仍由本机平台提供，不是双击任意目录文件运行。

选择新的配置再点击运行，属于**重新执行**：创建新编号与独立分叉，不会覆盖旧轨迹。分叉能否重做还依赖公共 RPC、源区块和部署状态。不能将离线浏览一次旧记录当作重新运行成功。

## 5. 常见情况与原有功能影响

- **未连接 / 服务令牌缺失**：确认运行的是 V0.18.2 平台，并刷新此页；不要把浏览器地址换成远程部署地址绕过本地访问限制。
- **RPC 超时、历史状态不可用**：换用另一内置公共节点，或对当前区块重开独立实验；失败运行保留用于分析。不要修改旧实验记录来使检查通过。
- **运行显示未知或停止**：先检查状态和错误，再决定是否新建实验。未知不代表链上失败，也不会触发自动重试交易。
- **重启后存在未完成记录**：系统标记为未知，不自动重放可能已经执行的操作；可查看现有证据后新建实验。
- **图较大**：页面最多显示 240 个节点和 1000 条关系列表；原始下载保留全部数据。事件列表最多显示最近 1000 条匹配记录。
- **导入失败**：只接受本功能导出的 JSON 包；路径、内容类型与大小会校验。原平台其他类型实验包仍从各自页面导入。

原有单 Agent、双 Agent、服务购买、跨路径预算、本地模型、采购隐私研究和公开测试网入口保持原架构与配置。新增模块不接管其钱包、模型或链状态。运行时仍共享机器 CPU、内存和网络资源，重负载可能影响同时运行的实验耗时；正式测量宜分别运行。

该说明描述本版开放能力，不替代本次发布的回归测试报告。具体通过、失败、受限项目应以保存的测试结果为准；公共网络可用性也可能变化。
