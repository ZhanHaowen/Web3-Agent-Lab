# Web3 Agent Lab V0.15.3 更新说明

本次说明覆盖 V0.13 至 V0.15.3 的累计更新。

## 主要变化

- **双 Agent 原子换币**：新增 Maker / Taker 角色、独立钱包与会话，支持询价、报价、接受及链上交割。
- **购买 Agent 服务**：新增 Buyer、Provider、Evaluator 与事后 Checker，通过服务托管完成报告交付、验收、付款或退款。
- **任务与 Agent 中心**：将任务定义、发布任务、执行实例和 Agent 配置分开，支持先发布、再上线并分配独立 Agent。
- **跨路径资产授权与预算控制**：新增正常交易与 Permit2 签名兑现的组合实验，对比分离计数和统一预算，核对实际资产流出。
- **通用分类与自定义金额**：支持预算内、超额、等额边界及单一路径对照；根据当前参数生成金额，支持六位小数。
- **统一操作与证据**：通过 start.cmd / stop.cmd 统一启停，侧栏同源切换，保留单步、证据导出与离线复查。

## 使用与验证

下载完整 Windows x64 运行包，解压后运行 start.cmd，从侧栏选择所需实验。

已发布便携包记录了 76 项单元测试通过，以及自定义金额、真实本地 EVM、平台集成、统一启停和原功能回归。逐项记录见 docs/V0.15.3验证摘要.md。

本次为 **Windows x64 预览版**，完整验收尚未完成；未提供本版 macOS 运行包。预算分离策略为受控研究对照，不等同于证明原版平台、真实钱包或 Permit2 存在漏洞。
