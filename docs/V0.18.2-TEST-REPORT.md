# V0.18.2 测试报告

测试日期：2026 年 11 月 19 日。版本：**V0.18.2 BNB SDK Beta**。本报告仅记录本轮实际执行的测试。

## 1. 结果与影响

- 原有根目录测试基线：227/227 通过。最终根目录测试：**250/250 通过**，新增 23 项 BNB 模块测试，未跳过。
- 保留 TypeScript 测试：145/145 通过；完整回归 **26/26 阶段通过**。
- 新功能独立于原 AgentKit、支付研究、预算与测试网模块；既有单 Agent、双 Agent、worker、服务交易、预算、支付研究及测试网任务均已回归。
- 真实 SDK 实验保留 7 次记录：5 次通过，2 次公网 RPC 不可用记为 unknown；未把 RPC 故障判成成功。3 笔成功交易均发生在本地 BSC 测试网分叉。
- GUI 离线浏览器夹具 6/6 组通过，含导入、图节点/原事件查看、回放、7 项文件下载、恶意文本与路径处理；纯离线入口 API 请求数为 0。它使用合成数据，不能替代真实 SDK 或链上验证。

实际平台 GUI 另完成 2 次真实 SDK 离线签名运行，均通过并记录 14 个事件；通过页面操作验证两个签名前检查点的暂停/继续、结果复查、节点详情与导出。首次记录保留了修正前的图关系，第二次验证最终 `signs-for-contract` 关系；两份原始导出均保留并注明版本差别，见 [实际 GUI 记录](test-results/v0.18.2/gui-live/gui-live-results.json)。这些离线签名运行同样不代表 HTTP 付款或链上结算。

Windows 便携候选包在新建短目录解压后通过 **17/17** 检查：无 node_modules，包内包含 Node/Anvil，并通过自带 Node 实际启动独立 SDK 进程，完成离线签名、验签、预算检查、8 类原始/派生数据导出、只读复查与退出。候选包和最终代码的 sourceHash 一致；最终压缩包仅补入文档和证据后重新打包，文件级 ZIP 校验值与候选包不同。建议解压到 `C:\Web3Lab` 等短路径；深层目录曾触发 Windows MAX_PATH，未声称消除系统长路径限制。见 [便携包记录](test-results/v0.18.2/portable/portable.json)。

| 场景 | 实际结果 | 已验证边界 |

| x402 离线签名 | 通过 | 实际 SDK 本地生成 EIP-3009 签名并验签；累计预算、未知代币与错误链拒绝；不进行 HTTP 付费或结算 |

## 3. 原有功能回归

26 阶段涵盖构建、诊断、类型检查、根目录/TypeScript 测试、测试网基础任务、原 API 与金额精度、双 Agent 合约及端到端、独立 worker 与崩溃恢复、服务购买、跨路径预算、启动/停止脚本、x402/AP2、MPP、支付失败对抗、研究托管、采购研究与推断数据流程。逐阶段命令、退出码和日志摘要见 [测试索引](test-results/v0.18.2/summary.json)。各集合存在包含关系，不应相加为不重复用例总数。

研究数据流程保留全部 36 个样本，其中 24 个任务结果为失败/未知，是预设失败与对照场景的真实标签；数据管线验证通过不代表 36 个任务全部成功。模型相关旧回归使用协议夹具，本轮未重跑真实商用模型或 Qwen3 全任务。

## 4. 开发中修复及最终复查

本轮修正了原始事件引用读取不一致、Anvil 子进程 PID 记录不一致、取消状态被迟到消息覆盖、工作进程 IPC 异常后未退出等问题，并加入针对性用例。实际 GUI 检查还修正了离线签名被误画成合约执行的关系；目前签名、读合约、提交交易与 EVM 执行明确区分。macOS 安装目录下的 Anvil 路径选择已补齐并通过单元测试，尚未在 Mac 真机运行。

完整回归启动后补入了图关系和 macOS 固定路径修正，因此保留最初日志，并对最终源码再次执行诊断、类型检查、全部 Node 测试。最终源码摘要：
