### 26 次开发构建实验

此组运行于开发构建 `d2aca5fc4049fbed81db0e08d5a2b9e3503a2b750e6266ef48885981b97a401c`，早于最后的数据完整性边界修复。原始记录保留该身份，用于模型行为分析，不替代最终构建验收。

1. 默认提示词：余额、转账、授权、兑换、兑换后存入各3次，**14/15 链上任务成功**。一次“兑换后存入”没有完成 Vault 所需授权，检查器判定失败。
2. 单独的工作流提示词组：强调读取工具结果、人类可读金额、检查各 spender 授权并完成全部步骤，五项任务各一次，**5/5 成功**。全文保存在实验配置中，未用脚本补交易。
3. 相同配置重新运行余额任务：**1/1 成功**，产生新实验编号；与只读回放区分。
4. 工作流提示词 + 连续模式：五项任务依次执行，**5/5 链上任务成功**，前序余额和授权状态保留。

26 次原始记录、调用终态对应关系、正文与运行时文件 SHA、离线检查一致性均通过独立复核。其中 **3 次出现 MODEL_TIMEOUT**，发生在所需链上操作已完成后的模型请求中：默认组两次“兑换后存入”，连续组一次。报告同时保留链上成功和模型请求错误，不描述成无错误完成；未提供的 usage 保留未知。

初版测试脚本错误地按旧 CLI `check` 退出码推断任务状态，将第一个真实任务失败误报为采集失败。现改为解析 CLI 输出的 JSON 结论。原始 `summary.json` 和日志不覆盖，独立复核写入 `summary.reviewed.json`。

### 独立 Agent 与混合后端

最终构建上以两个独立 worker、独立钱包、同一真实 Anvil 链执行两组原子换币（10 TokenA 换20 TokenB）：

- **local-local：通过。** 双方均实际调用托管 Qwen，12次请求、12次响应、0模型错误，4笔成功交易；耗时99.328秒，18/18项集成断言通过。
- **local-api-fixture：通过。** Maker 调用真实本地 Qwen，Taker 使用带测试 API Key 的协议服务，合计12次请求、12次响应、0模型错误，4笔成功交易；耗时67.204秒，19/19项断言通过。API 方是可控协议夹具，不是商业模型。

两组均验证：两个 worker PID 与主平台/推理引擎分离、独立钱包、实际后端选择、完整请求/响应及调用归属、运行时原文自包含、成本与失败调用计数规则、全部交易归属本次任务、链扫描无漏记、图无悬空关系或事件引用、秘密不进入包及解码日志、离线 verify/check/replay 通过。独立检查器结论均为 success/filled；各有一份共享推理会话的 runtime_evidence，不把它解释为角色独占日志。

37项断言全部通过。测试结束后4个测试 worker 均正常退出，未停止或接管其他用户进程。两组各一次，仅证明本版链路可实际跑通，不构成多 Agent 稳定成功率结论。
