# V0.18.0 Testnet Beta 验证报告

本版 package 为 `0.18.0`，发布标签为 `V0.18.0`，发布修订为 `testnet-validated-preview`，以 GitHub prerelease 提供。**历史候选验证与 V0.18.0 发布构建验证分别记录，不能互换源码摘要或运行编号。**

## 1. 功能与实验范围

独立测试网入口开放 Base Sepolia、BNB Smart Chain Testnet、Arbitrum Sepolia、OP Sepolia、Polygon PoS Amoy、Avalanche Fuji C-Chain 六个 EVM 配置；其余十四个网络只是候选目录。

五类基础任务为查询余额、转账、授权、兑换、兑换后存入，使用六位小数实验币及自有 LabAMM/LabVault。支持脚本基线、API/local 双后端、工具返回干预、两处暂停、连续状态、原始记录、图导出及离线回放。

所有自动写链测试使用**本地隔离真实 EVM 与受限标准 RPC**。没有使用真实公网账户部署合约或成交；六个 chainId 配置的回归不是六条公网的端到端验收。API 模型协议 fixture 也不等于商业模型实测。

## 4. 回归集合及关键断言

`scripts/testnet-regression.mjs` 顺序执行 26 个阶段：预算构建、平台构建、自检、接口类型检查、根目录单测、保留 TypeScript 测试、测试网集成、原 API、授权矩阵、双 Agent 合约与集成、独立 worker、关停恢复、服务合约与集成、预算核心/参数/主入口/HTTP、Windows 启动器、x402/AP2、MPP、支付异常、研究托管、采购研究引擎及数据集评估。

新增测试网的主要检查包括：

1. 六配置的 chainId/权限边界；禁止从 HTTP 开启测试专用 loopback 选项，禁止主网和目录项绕过白名单。
2. 五任务连续执行、六位小数、人类金额校验、初态授权与本次消耗、任务所属交易与独立结果断言。
3. 无私钥只读连接、显式部署、清单身份校验、重启后重新接入；不把连接成功视作部署成功。
4. 待确认/未知交易保留哈希，广播成功但响应丢失、重启及迟到回执后只读对账，证明没有重新付款。
5. 工具前/交易前暂停、并发拒绝、取消；慢日志中的继续、取消及写失败确定性测试，证明记录未完成时不放行交易。
6. 当前链复核不误用后续任务状态；锚点重组或 RPC 缺失保留未知；离线检查不得将外部证据未知升级为成功。
7. 实际模型请求/响应保留与凭据清洗；任务→模型→工具→合约→交易的显式关系及原始事件引用，缺失 EVM trace 明确标注。
8. 原始记录 SHA-256、派生图完整性、导入后的零在线请求、节点点击、事件查看、失败和取消记录可导出。
9. 本地模型冷启动及并发准备互斥；模型/运行时身份和运行证据保留，证据缺失不能判为完整成功。
10. 确认数配置范围为 1–64；前后端拒绝 0/65，接受边界 1/64。

## 5. 原有功能影响

原 `app.js` 未重写。原本地 Anvil 初始化、重置、快照、单 Agent、双 Agent、独立 Agent、服务购买、预算及采购支付研究保留原入口和环境。上述场景仍在本地运行；测试网新增入口不能说明 x402/AP2/MPP/托管研究已经迁移至公网。

测试网使用独立 `/api/testnet/*`、会话令牌和 `data/testnet/`，不迁移用户旧数据库。测试网与原单 Agent/任务中心写入互斥；独立预算和研究链仍各自管理。文件完整性、封存证据离线重算与当前链上复核分别实现，不以一种检查替代另一种。

本版实际基础任务检查器标识更新为 `2.3.0`，服务回退标识跟随运行时常量；已发布任务中心定义中的 `legacy-2.2`/`1.0.0` 标签和定义哈希为兼容而保留，不改写历史定义。具体结果应读取对应检查结果的 `checkerVersion`，不要仅凭任务模板名称判断执行的检查器版本。此项不代表任意旧数据库迁移已经验收。

研究账本另增加 Windows 原子重命名瞬态错误的有限重试，最多 8 次、累计等待 1.125 秒，只重试已写字节的文件替换，不重试付款或业务变更。永久错误继续失败，确定性故障注入覆盖成功恢复、耗尽、非瞬态和非 Windows 行为。

## 6. 已知限制与保留失败

- 无公网重置、快照或人工出块；新运行使用当前状态，不能承诺复现原始初态。
- 不协调外部钱包/另一平台进程的 nonce。长期未发现交易或同 nonce 外部替换不会自动解除未决锁，没有自动替换/取消/丢弃恢复。
- 当前检查扫描最多 1000 个区块；RPC 不提供历史信息、重组或超出上限会得到 `unknown`。
- 自有 Lab 合约不等于第三方 DEX 或真实协议流动性；本版未实现全模块多链化。
- EVM 内部 trace 取决于 RPC；执行 gas 不包括未归一化的 L2 额外网络费用。
- 真实 Qwen 失败样本保留，不能把采集通过率写成任务完成率。
- 任意历史数据库迁移、macOS 真机、商业模型组合与公网逐网写入未全面验证。
- 旧 AT 补充套件仍有历史部分项，不将可执行断言通过写成 AT01–36 全部完成。
- Windows 深层解压可能触发路径长度限制，运行包应解压到短路径。

开发历史中的 24/26、25/26 及慢日志暂停竞态失败均保留：分别涉及测试目录/构建期间变动、旧恢复链端口占用、Windows EPERM 账本替换，以及暂停状态早于恢复控制器可用。修复采用隔离端口、有限文件重试及确定性暂停测试，未放宽财务或任务断言。
