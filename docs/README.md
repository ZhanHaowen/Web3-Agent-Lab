# V0.17.0 Research Beta 文档索引

当前发布版本为 **V0.17.0 Research Beta**（package：`0.17.0-beta.1`）。本版在 V0.16.0 基础上增加采购与支付轨迹研究模块，保留原单 Agent、多 Agent、服务购买、预算控制与本地/API 双后端。新功能、旧功能回归和未验证范围分别记录，不将历史测试结论直接套用于本版。

## 本版先读

- [V0.17.0 更新说明](V0.17.0-RELEASE-NOTES.md)：四项隐私研究能力、六种支付部署、原有功能影响和实现边界。
- [V0.17.0 研究操作指南](V0.17.0-RESEARCH-GUIDE.md)：启动、采购任务、公开/私有文件、推断评价、CLI 与源码复现。
- [V0.17.0 测试报告](V0.17.0-TEST-REPORT.md)：本次 Windows 实测结果、原功能回归、真实模型失败及尚未验收内容。
- [本地模型与双后端操作指南](V0.16.0本地模型与双后端操作指南.md)：配置继续适用于本版；Qwen 权重仍需单独导入或显式下载。
- [模型原生数据说明](V0.16.0原生模型数据.md)：原始 HTTP、运行时资料、脱敏与未知字段的解释。

## 发布、验证与历史资料

从 [V0.17.0 Release](https://github.com/ZhanHaowen/Web3-Agent-Lab/releases/tag/V0.17.0) 选择 Windows 运行 ZIP 附件。GitHub 自动生成的 Source code ZIP 不含完整便携运行程序，源码安装需按当前研究指南安装根依赖和隔离支付依赖。

本版实测范围以 [V0.17.0 测试报告](V0.17.0-TEST-REPORT.md)为准；远端 CI 以对应提交的 Actions 结果为准。`build-info.json` 标识构建和源码摘要，实验 `integrity.json` 校验封存文件；完整性通过不等于任务成功或隐私攻击有效。

- [V0.16.0 更新说明](V0.16.0更新说明.md)与[回归报告](V0.16.0回归测试报告.md)保留本地/API 后端引入时的证据。
- [V0.15.3 源码同步记录](repository-sync-v0153-validation.json)、[验证摘要](V0.15.3验证摘要.md)、`v0153-*.json` 均是历史记录。
- [V0.15.3 便携构建身份](releases/V0.15.3-portable-build-info.json)与[仓库同步清单](releases/V0.15.3-github-overlay-manifest.json)用于区分当时的附件和源码迁移。
- [V0.15.1 证据索引](验收证据索引_V0.15.1.md)和[最终摘要](最终验证摘要_V0.15.1.md)保留当时的未完成条件。
- [archive/v0.13](archive/v0.13/README.md)保存旧通用文档。历史文件不回填成新版本测试结果。

公开观察者包可作为攻击输入；私有完整包与推断评估文件含真实任务、预算及策略标签，只用于研究者核验。Windows 已完成本版记录中的实测，Mac 真机、旧数据库自动迁移和生产网络不在本版验收承诺内。
