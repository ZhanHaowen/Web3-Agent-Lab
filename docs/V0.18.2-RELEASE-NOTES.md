# V0.18.2 BNB SDK Beta 更新说明

发布日期：2026-11-19。基于原 V0.18.0 平台增量开发；新增模块使用 BNB Agent SDK 0.6.1，上游固定提交 `260e16196931780d0370bd3a9d9b67ece744bb9d`。本次为本地交付，尚未推送 GitHub。

## 本版解决什么问题

研究者现在可以在平台内独立测试 BNB SDK 的签名、身份登记和部分托管任务操作，查看实际调用与链上结果，而无需将 SDK 替换进现有 Agent 的底层工具。新入口为 **BNB SDK 实验室**（`/bnb-sdk.html`）。

SDK 本身是协议与钱包工具，不是语言模型。本模块运行确定的 SDK 实验脚本；原平台的真实模型实验继续通过原入口执行。

## 已开放的四类实验

1. **x402 离线签名与预算**：临时钱包实际生成 EIP-3009 签名并验签；检查累计额度、未知资产和不支持的链。不会提交 HTTP 付款或链上结算。
2. **公开部署只读探测**：对 BSC 测试网 97 或主网 56 检查链、区块、合约字节码、实际代理实现及代币元数据。记录实际实现，不把 SDK 配置中的实现地址当作当前链上事实。
3. **ERC-8004 分叉身份登记**：固定 BSC 测试网源区块，在独立本地 Anvil 分叉执行真实注册交易，读回身份和所有权，再验证快照恢复。
4. **ERC-8183 分叉托管任务**：创建未注资任务、读取状态、取消任务，再检查交易回执、任务归属、零预算及快照恢复。此范围不包含已付款退款。

ERC-8183 与 x402 的 U 代币不是同一地址或精度；分别采集配置和元数据，不复用六位精度假设。公开链仅只读，本地交易使用临时实验账户，不使用用户的真实资金。

## 记录与操作方式

- 每次实验独立编号、子进程、临时钱包和数据目录。现有模型密钥不会传入 SDK 子进程。
- 原始事件采用 JSONL、内容寻址数据及连续摘要；原始文件与图、检查结果分开保存。
- 留存操作参数与返回结果、区块/部署信息、交易与回执、可取得的 EVM 内部调用以及暂停和错误事件。私钥和可复用付款签名不导出。
- 独立检查器核验记录完整性、同次实验关系与已采集状态证据；不会仅依据 SDK 返回“成功”作结论。离线签名复查检查的是留存证据，不会重新验证未导出的签名。
- GUI 可在操作前暂停、继续或停止，查看事件与图节点，重新检查，下载完整 JSON 实验包、图 JSON、GraphML、节点/关系 CSV、详细轨迹和原始 JSONL。
- 支持纯离线回放入口 `?offline=1`。只读已保存数据，不调用模型、链或执行服务，也不补造缺失关系。
- 图中签名是 `signs-for-contract`，读取是 `reads`；只有真实交易证据才产生交易及 EVM 执行关系。

## 对原有功能的影响

原有单 Agent、双 Agent、独立 Agent 进程、服务购买、预算控制、API/本地模型、采购隐私研究和测试网基础任务保持原实现与入口。没有迁移旧实验数据，没有接管旧钱包或原 Anvil 实例。

新模块在同一平台服务中挂载路由，但业务执行和依赖隔离：原依赖的 viem 2.38.3、Zod 3 保留；SDK 在 `packages/bnb-sdk-lab` 使用独立锁文件及打包运行时。上游源文件摘要与许可证一并保留。运行时仍共享机器资源，做性能测量时建议避免同时运行多个模块。

具体回归结果见 [本次测试报告](V0.18.2-TEST-REPORT.md)。通过本次测试不等于所有真实模型、所有公网环境或 macOS 真机都完成验收。

## 已修正并覆盖测试的问题

- 修正原始数据引用字符串的读取，保证事件详情可展开。
- 修正取消中收到迟到暂停消息导致状态回退的问题。
- 补齐 worker 启动、IPC 异常与超时清理，防止活动锁提前释放而子进程继续运行。
- 检查器拒绝路径越界、符号链接和过大证据；畸形记录返回失败，不误报通过。
- 导入离线包后取消轮询和在途请求；旧响应不能覆盖离线回放。
- 修正签名图的关系类型，避免把离线签名显示为合约执行。

## 已知边界

完整注资、履约、结算、退款、真实 x402 HTTP 采购、TWAK/Altana/Turnkey 及代付服务均未开放。公共 RPC 可用性和历史状态保留受外部节点影响；本次出现的超时保留为未知，不能计作业务通过。固定区块与代码版本帮助重做实验，但不保证未来任意公共节点仍能提供历史状态。

完整实验包是研究者视图，不是隐私研究的攻击者视图。哈希链可以检查保存数据的一致性，不代表独立时间戳或链上公证。

## 启动与复现

Windows 便携包请解压到较短目录（例如 `C:\Web3Lab`），然后运行 `start.cmd`；未开启长路径支持时，过深目录可能无法完整解压。在首页选择“BNB SDK 实验室”。既有本地模型权重仍需单独准备。

源码构建使用固定 Node 24.19.0 和 pnpm 11.19.0：

```text
pnpm install --frozen-lockfile
pnpm run setup:research
pnpm run setup:bnb
pnpm run build
pnpm start
```

首次从源码运行还需按原指南准备 Anvil；Windows 便携包已附带 Node 与 Anvil。测试命令：

```text
node --test tests/bnb-sdk-*.test.mjs
node scripts/bnb-sdk-smoke.mjs
node scripts/bnb-sdk-smoke.mjs --fork
node scripts/testnet-regression.mjs
```

`--fork` 需要联网读取公共 RPC，交易仍只发给本机。离线 smoke 不联网，输出默认在 `artifacts/bnb-sdk-smoke`；可用 `LAB_BNB_TEST_OUT` 指定隔离目录。四场景说明、导出结构和故障处理见 [操作手册](BNB-SDK-LAB-V0.18.2.md)。
