# V0.14 需求与交付对照

本版交付双 Agent 本地原子换币场景，保留 V0.13 单 Agent 发布程序的兼容入口。范围对应设计方案中的 peer_swap，服务购买与外部支付协议留待后续版本。

| 要求 | 本版实现与验证边界 |
|---|---|
| 独立 Agent 与钱包 | 固定 Maker/Taker，独立钱包、对话、工具、收件箱、私有目标和成本；不注册额外角色 |
| 场景轮转 | 显式 step、等待、预算、暂停与停止，同链外层锁，逐钱包串行提交 |
| 协商 | 询价、报价、接受、还价、拒绝、订单引用；接受必须来自报价对手且经过消费记录 |
| 原子交换 | Maker 托管 A，Taker 在一笔 fill 内付 B 并收 A；固定资产与参与方，无部分成交 |
| 订单安全 | scope、链 ID、合约、Maker、salt 绑定；规范 ABI termsHash；期限、取消、清退和终态检查 |
| 转账与重入保护 | 本地实现重入锁和可选返回值检查，仅允许不可变 LabToken；未引入 OpenZeppelin 包 |
| 金额和旧授权 | 人类单位转换一次，整数目标校验；已有足额 allowance 可跳过授权 |
| 广播未知 | 先记录意图，按发送账户、nonce 和 calldataHash 对账；原 salt 查单，禁止自动换 nonce 重付 |
| 消息幂等 | 本地 outbox/inbox，episode/message ID 去重，sent/delivered/consumed/duplicate 事件 |
| 通信干预 | 首版使用可靠本地投递；延迟、丢包、改写及外部 A2A 尚无 GUI 模板 |
| 独立结论 | 结算、业务结果、双方目标和完整性分开；离线检查不联网 |
| 溯源与导出 | schema v2、角色命名空间、显式因果边、GraphML、CSV、事件、执行轨迹和哈希清单 |
| GUI | 角色配置、消息、订单、资产、成本、暂停、单步、出块、退款、导出与离线导入 |
| 回放和重跑 | 回放只读；共同初态新 episode 重跑；无跨进程任意检查点续跑 |
| 兼容 | 原单 Agent API 与 GUI 保留，旧包由原 reader 读取；未补造旧包的跨 Agent 关系 |
| 源码 | 新增 ESM/Solidity 源码和原 lockfile；旧 TypeScript 未随基线包提供，保留可审查原 bundle |
| 发布平台 | Windows x64；未提供新 Mac 原生运行包或 Mac 实机验收 |
| 模型验证 | 实现双独立兼容工具调用端点；自动测试使用显式协议替身，未采集真实云模型能力数据 |
| V0.15 | service_purchase、Evaluator、A2A/x402/AP2 等未实现，不以普通转账替代这些协议 |

原方案 T01 至 T14 的具体通过项、部分覆盖项与未验证项见 v014-acceptance.json。测试替身、源码缺失和跨平台边界不计作通过。
