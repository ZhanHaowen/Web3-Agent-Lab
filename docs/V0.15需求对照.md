# V0.15 需求与实现对照

对应原设计稿“服务购买与外部协议的第二阶段”和T15服务扩展。

| 要求 | 本版实现 |
|---|---|
| service_purchase独立结算 | 固定settlementMode=service_escrow，独立LabServiceEscrow，不复用普通转账冒充购买 |
| 固定区块余额报告 | 固定blockNumber及blockHash，查询实验TokenA/B和Buyer/Provider/Recipient，交付版本化JSON |
| Buyer与Provider自主决策 | 脚本与双独立LLM会话，私有预算/最低价格，真实报价和接受消息；固定实验价，不开放自由议价 |
| 独立Evaluator | 独立身份及钱包，确定性balance-report-v1，提交链上验收/拒绝；支持错误批准、错误拒绝和离线 |
| 事后Checker只读 | 与Evaluator分开重新读取和校验；付款成功但内容不合格必须失败，离线可重算 |
| 出资预算 | 创建和出资分开，fundJob检查expectedBudget，固定支付TokenB、Provider和Evaluator |
| 生命周期 | Created/Funded/Submitted/Completed/Rejected/Refunded/Cancelled；明确到期不自动退款 |
| T15故障覆盖 | 错误报告、错误验收、离线、不交付、重复结算、预算与角色、期限边界，均有本地EVM用例 |
| 运行器复用 | 轮转支持三个角色，使用原共享链锁、钱包串行、意图日志、广播未知对账 |
| GUI与交互 | 左侧配置右侧结果，耗时与按钮反馈，报告/质量/资金独立呈现 |
| 证据与回放 | 事件、交付物哈希、验收、图与离线包，旧单Agent与peer_swap保留 |
| Windows交付 | 自带Node/Anvil，ZIP文件清单与SHA256；macOS未提供新增包或实机验收 |
| 外部互操作 | A2A、x402、AP2、ERC8004暂不实现，未冒充兼容 |

模型协议夹具和真实云端模型测试分别标记；当前没有云端模型能力数据。版本的功能通过不能据此宣称已做完整安全审计。
