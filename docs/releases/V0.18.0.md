# V0.18.0 Testnet Beta

版本：`0.18.0`；GitHub 标签：`V0.18.0`；发布修订：`testnet-validated-preview`；发布类型：**prerelease**。

本版为原本地研究平台新增可选测试网基础任务入口，保留经过隔离真实 EVM 回归验证的连接、合约、任务、记录和复查路径。**六个测试网配置已开放，不代表六条公网已完成部署或成交验收。** 原多 Agent、服务购买、跨路径预算和采购支付研究继续在本地运行。

## 新增能力

- 六个 EVM 配置：Base Sepolia `84532`、BNB Smart Chain Testnet `97`、Arbitrum Sepolia `421614`、OP Sepolia `11155420`、Polygon PoS Amoy `80002`、Avalanche Fuji C-Chain `43113`。另外十四个目录项不开放执行。
- 新页面 `/testnet.html` 与独立 `/api/testnet/*`，支持只读连接、明确的写入账户、Gas 检查、显式部署以及验证后导入/导出部署清单。
- 自有六位小数 LabToken、LabAMM、LabVault 的五任务：余额、转账、授权、兑换、兑换后存入；人类金额与任务目标先校验，固定连续链状态。
- 复用脚本、兼容 API 及本地 Qwen 后端；任务输入、提示词、工具列表、工具可见返回可配置，支持工具前及交易前暂停和停止后续操作。
- 关联任务、模型请求/响应、工具、合约、交易、回执与可获取的内部调用；原始事件与派生图分离，导出图 JSON、GraphML、节点/关系 CSV、详细轨迹及完整实验包。
- 三种独立检查：文件完整性、封存证据离线重算、当前链上只读复核。导入回放后不请求链、模型或在线平台接口。
- 未决交易哈希及意图持久化；重启、确认超时或广播响应丢失后仅查询原交易，不自动再次签名、广播或付款。

## 修复与数据可靠性

- 对任务所属交易、初态授权及本次消耗做独立检查，避免只看交易成功或 Agent 的文字结论。
- 检查前后核验区块锚点；重组/缺少 RPC 证据保持未知，离线重查不将未知外部证据升级为成功。
- 修复暂停状态提前暴露的竞态；恢复控制器与状态同步设置，早到继续不会跳过日志写入。暂停/恢复日志写入期间取消或写失败均阻止后续提交。
- 修复研究账本在 Windows 短暂文件占用下的原子替换失败：有限重试同一文件重命名，不重试采购或支付，永久错误仍失败。
- 保留函数 ABI 签名等非秘密溯源字段，清洗私钥、API 凭据和签名秘密；无法取得的内部 trace 与未归一化费用明确标注。
- 确认数输入统一为 1–64，前后端校验一致。实际基础任务检查器更新为 `2.3.0`；已发布任务中心定义中的 `legacy-2.2`/`1.0.0` 标签和哈希为兼容保留，具体运行以结果的 `checkerVersion` 为准。

## 对原功能的影响

原首页增加环境入口，原 `app.js` 未重写。原 Anvil 重置/快照、单 Agent、双 Agent、独立 worker、服务、预算及研究功能仍使用原本地环境。测试网数据独立保存于 `LAB_DATA_DIR/testnet/`，不自动迁移旧数据库。

测试网与原单 Agent/任务中心写入互斥；独立预算和研究链仍各自管理。这不是全平台统一交易锁，也不是将所有研究协议迁移到测试网。x402/AP2/MPP/ERC-8183 研究部署沿用原本地能力及限制，详见 [V0.17.0 研究指南](../V0.17.0-RESEARCH-GUIDE.md)。

## 使用与升级

1. 从 [V0.18.0 Release](https://github.com/ZhanHaowen/Web3-Agent-Lab/releases/tag/V0.18.0) 下载 `Web3-Agent-Lab-V0.18.0-Windows-x64.zip`，解压到新的短路径可写目录。不要覆盖正在运行的旧版本。
2. 停止旧平台，保留其数据及导出包，双击新目录 `start.cmd`。模型权重单独导入或准备，不随源码分发。
3. 首页选择本地 Anvil 或公开测试网。测试网需 HTTPS RPC、专用测试钱包和原生测试 Gas；无私钥可只读接入已有清单。连接不自动领币、不自动部署。
4. 明确部署或导入清单后先运行脚本基线，再运行模型实验；未知交易先只读对账，不重复付款。
5. 运行封存后导出证据，利用离线回放和独立检查核对结果。旧数据不自动迁移，任意历史数据库兼容性未全面验收。

完整步骤见[测试网操作指南](../TESTNET-PREVIEW-GUIDE.md)。GitHub 的 Source code ZIP 不含便携运行程序，应按 [README 源码开发](../../README.md#源码开发)安装依赖并构建。发布附件的 SHA-256 与证据清单随资产提供；当前 GitHub Actions 状态以对应提交为准。

Windows 运行 ZIP 排除 `*.log` 与嵌套 `*.zip`，不是完整验收证据包。需要测试日志、历史样本 ZIP 和索引时，请下载同一 [Release](https://github.com/ZhanHaowen/Web3-Agent-Lab/releases/tag/V0.18.0) 的独立 **Test-Evidence** 资产，或读取仓库中的[本地/历史证据](../test-results/v0.18.0/)及[CI 证据](../test-results/v0.18.0-ci/)。

## 明确不包含的能力

本版没有公网重置/快照、主网交易、自动领币、第三方 DEX/真实协议流动性、其他十四个目录网络的执行、多 Agent/支付研究的公网迁移、跨进程 nonce 协调、自动替换未知交易或隐私支付协议实现。六网公网可用性应逐网另做专用账户、Gas、部署、五任务与回执验收。
