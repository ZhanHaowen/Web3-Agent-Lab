## 发布范围与边界

发布包含完整可维护源码、固定依赖锁文件、受测构建入口、更新说明、测试报告和可公开测试摘要。GitHub 自动生成源码归档；本次没有新 EXE 或便携运行包，未携带本机 runtime、模型权重、用户数据库、私钥、API Key 或私有签名恢复缓存。

AT-15 的双方分别显式拒绝仍属于部分覆盖。研究数据集中失败或未知样本仍保留，不因流程测试通过而被标为任务成功。未完成真实 LLM 全组合、公网写交易、macOS 真机、GUI 录屏、新安装包及链重组验收。

缺少接受快照的旧版未完结任务不自动迁移；切换前先在旧版核对 pending 交易和清理开放托管资金。新恢复机制直接验收的是本地 `peer_swap` 两条执行路径，不代表所有支付协议新增了相同保证。
