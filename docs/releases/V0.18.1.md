# V0.18.1 跨路径资产授权与预算模块替换版

本版在 V0.18.0 基础上更新跨路径资产授权与预算控制，迁入 20261116 修订中的模型任务、共同预算、策略约束和智能账户实验实现。其他业务模块保留 V0.18.0，发布类型继续为 Testnet Beta。

## 替换范围

- 预算页面、交互、样式与离线证据检查。
- 预算 Agent 决策、任务金额确认、共同预算、有效期、白名单、高风险动作及人工审核。
- 本地受限 EOA 与 BudgetSessionWallet 智能账户实验后端、合约源码和对应产物。
- 预算模块的测试与历史修订记录。

预算模块按供体版本工作，旧版分离计数预设页面不再是当前预算入口。模型调用、钱包实际执行、链上结果与任务检查分别保留。预算100、要求80与60的任务不会自动改成80与20；是否被拒绝、是否完成原任务以实际记录为准。

## V0.18.0 保留范围

测试网页面、网络配置、测试网服务和合约、研究协议模块、单 Agent、多 Agent、任务中心、服务购买、本地模型管理、模型采集和旧版编译核心均保留底包实现。Node、Anvil 和本地推理运行程序保留原文件。

为接入预算模型，仅在主服务兼容桥补入预算 ActionProvider、本地模型解析及身份检查，并增加预算正在使用本地模型时的配置变更保护。保留 V0.18.0 的测试网路由、互斥和停止规则。预算内使用等价的端点校验函数，避免替换共享模型代码。

## 使用

完整解压到新的短路径目录。停止旧版本后双击 start.cmd，进入侧栏“跨路径资产授权与预算控制”。不要覆盖正在运行的旧目录。

使用本地模型需重新指定已有模型文件与引擎路径；权重不包含在本包中。API 模式按所用服务填写兼容端点与模型。导出包与旧数据不自动迁移。

## 核验

本次实际验证集合、执行状态及证据位置见同目录 V0.18.1-validation.json。文件替换和保留范围见 V0.18.1-transplant-audit.json；全包文件哈希见根目录 release-manifest.json。

原 V0.18.0 及供体历史报告均保留原版本与构建身份，不视为本次重新执行的记录。本次模型接口回归使用协议夹具，本地模型解析通过受控测试验证；未据此宣称商业模型或真实 Qwen 的任务成功率，也未执行公网交易。

供体中的运行数据、SQLite 数据库、管理令牌和本机秘密不迁入发布包。新测试产生的数据与日志存于构建验证目录，不随运行包分发。
