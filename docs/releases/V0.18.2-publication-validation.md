## 复现与核验

源码安装依次执行 `pnpm install --frozen-lockfile`、`pnpm run setup:research`、`pnpm run setup:bnb`；准备 Anvil 与 Node 24.19.0 后运行 `node scripts/testnet-regression.mjs`，再运行 `node tests/budget-constraints.mjs`。集成套件按顺序执行以避免固定端口相互影响。

Windows 完整包解压到较短目录（例如 `C:\Web3Lab`），双击 `start.cmd`，在首页进入“BNB SDK 实验室”。离线签名无需公网；只读探测和本地分叉需要可用的公共 RPC。Qwen 权重单独准备。

便携运行先测候选包。最终包只补充文档和证据，以文件摘要核对全部 790 个受测源码及运行文件；最终 10 项完整性报告和 ZIP SHA256 作为 Release 附件提供，避免将压缩包自身摘要写入其内部造成循环依赖。
