QUICK START
第一次使用
  1. 初始化链环境
    在「链与环境」点击初始化，等待合约与账户准备完成。先使用默认本地链。
  2. 完成一条脚本基线
    选择转账任务，使用「脚本基线」运行。基线用于核验软件，不代表 LLM 的能力。
  3. 检查事实是否完整
    查看行为轨迹与独立检查结果，展开事件了解提交参数、交易回执与状态变化。
  4. 配置真正的 LLM Agent
    重置环境，切换 LLM Agent，填入兼容端点、模型与密钥。模型需支持工具调用。
  5. 导出与复现
    导出实验包留存原始证据。在档案中回放记录；独立重跑产生新编号，连续实验按当前状态继续。
读懂实验结果
成功
链上证据满足任务断言，未发现未解决的必要交易。
失败
存在足够证据证明目标未达成或执行违反任务条件。
等待确认
已知交易尚未确认；可手动出块后再次检查。
结果未知
缺少必要证据或 RPC 查询失败，不能据此断言成功。
取消运行不等于撤销交易：已提交的交易可能仍会被确认。请检查链上状态。
数据与实验边界
  • 独立实验每次恢复标准基线；连续实验继承当前状态。当前余额预览不是锁定初态，实际起点以 state.before 为准。
  • 连续历史实验不能原样重跑。会话和前次运行关系保存在各自配置中，手动恢复快照后新建运行仍是新实验。
  • 状态表默认以人类单位显示运行前、后和变化量，可勾选查看原始整数。交易执行成功与任务成功分开判定。
  • 数据保存在本机，原始事件与后续检查标签分开保存。
  • 界面只展示接口实际返回的模型内容，不采集模型内部思维。
  • 模型重新调用可能产生不同输出，即使初始链状态一致。
  • 本地 AMM 与 Vault 用于受控实验；真实协议研究需另行适配任务和检查器。
  • 不向实验环境导入真实资产、个人钱包或生产私钥。
常见操作
交易停在等待确认：先检查自动出块开关，或手动出块。环境无法启动：查看启动终端中的 Anvil、端口和依赖错误。模型无响应：核对端点、模型工具调用能力和密钥。
详细部署步骤、数据格式及技术选型见软件包内的操作手册与 docs 目录。
